### A6 · ⚠️ 三大前沿模型被"电子游戏"骗过：自主武器测试几乎没有防线

Vals AI 的测试显示：在模拟的自主武器情境里，Anthropic、OpenAI、Google 的主流模型**轻易把医护人员、记者、投降士兵标记为自杀式无人机打击目标**。更麻烦的是绕过方式——不需复杂越狱，**一句电子游戏情境的提示词**就让拒绝响应失效，而那点拒绝还来得太晚。三家已承诺修复。

这轮测试的价值不在排名，而在它证明：**安全对齐是脆的，换个叙事框架就掉**。防御写在"我拒绝回答"上，攻击发生在"这不是真的，这是游戏"的包装里。

**⚡ 跟你**：你自己搭 agent 时这条直接适用——工具权限要卡在系统层（能不能调这个 API），别只靠 prompt 里那句"不要这么做"。

### B1 · Meta 把用了八年的设计系统开源：一周 13,501 星

第 47 周（11/09–11/15）GitHub 热榜第一是 `meta/astryx`，周增 **13,501 星**、总星 28,867。这是 Meta 内部长了八年、撑着 **13,000+ 个应用**的设计系统，开源版是 Beta：**150+ 可访问组件**，React 19 + StyleX，带主题、暗色模式、模板和 CLI，最新 v0.7.16。

真正的卖点是那句定位——*"by people and the agents working alongside them"*：API、约定、文档、CLI 一起设计；CLI 全局装一次，任何目录可用，项目内跑项目自己那版；每个组件遵循同一套命名与组合规则，学几个就能推断剩下的。

README 里的那句话值得抄下来：**"每一处让 AI 更好用的改动，也让人更好用。"**

**⚡ 跟你**：你做页面最常崩的不是审美，是"AI 不知道你的间距规矩"。把间距、圆角、动效时长写成文档 + 一条 CLI，agent 就有了可读的参考——比在 prompt 里贴十条"请保持简洁"有效得多。

### B2 · craft-anything 一周涨 28,744 星：先"看懂"任何软件，再让 agent 帮你造

11 月 3 日才公开的 `storytold/craft-anything`（Apache-2.0），到 11 月 15 日已 **32,640 星**，单周新增 **28,744**。它做的事一句话：**把"读懂一个软件怎么跑的"变成可执行的取证流程**。

形态四步：Study（抓目标在每个宽度下的页面、代码、文件、运行方式）→ Build（交给 coding agent 照着造）→ Check（自检）。底层 **320 个工具，每个既是 CLI 命令也是 MCP 工具**，任何 agent 都能驱动；不用 AI 也能纯手查。

争议也在这：这类工具天生踩在"逆向 / 复刻"的灰线上。有梳理指出，10 月底 Claude Code 系统提示词刚加了"不要复刻具体已有游戏、改名自称原创也不行"的限制，四天后 craft-anything 上线——**工具能力和版权边界在互相追着跑**。

**⚡ 跟你**：你看别人站点的动效，现在是截图 + 猜 CSS；这套流程是量出真实数值再复现。对创意项目是加速器，但商业交付里只学结构、别搬素材和字体。

## 🔬 研究前沿

### C1 · Nature 刊出"AI 原生实验室"：湿实验的排班、执行、记录交给系统

11 月 4 日，Nature 刊出 *An AI-native experimental laboratory for autonomous biomolecular operations*（上海交大等团队）。它不是"AI 出主意、人做实验"，而是把**生物分子操作的编排、执行、记录整条链路**交给系统。

为什么单列：湿实验容错率远低于软件——试剂、温度、时序任何一步偏了结果就废。能在这种环境里做自主闭环，说明"AI 做科研"从"读论文提假设"推进到了"动手"。

旁证：Nature Protocols 11 月 16 日的机器人 + 机器学习流水线发现全天然塑料替代物；arXiv 上 LLM agent 做粉末 XRD 结构解析（见 C2）。

**⚡ 跟你**：这套方法论和你做前端回归测试一样——先有"可判定的结果"，才谈得上自动化。你验收页面的标准越具体，agent 能替你干的活越多。

来源：[Nature 11/04](https://www.nature.com/articles/s41586-026-11228-6)

### C2 · 给 agent 一个能打分的靶子，它就能自己"爬山"解晶体结构

arXiv 2611.17539（11 月 12 日，Alán Aspuru-Guzik 等）：用 LLM agent 做粉末 XRD 晶体结构解析，方法是 **hill-climbing + 可验证评分**——每步提出结构修正，用模拟衍射图与实测图的匹配度打分，只保留变好的那步。

另一条来自 X 转述：去中心化 agent 通过共享留言板协作搜索分数拓扑态结构，报告**能隙提升 10–15 倍**并给出解析解释。共同点：**不是让模型更聪明，而是给它一个可计算的"对不对"**。

**⚡ 跟你**：想让 agent 靠谱，先给它一个能自动判分的检查项（截图 diff、Lighthouse 分、类型检查），而不是让它自己说"我完成了"。这一条能挡掉你八成"看起来做完了其实崩了"。

来源：[arXiv 2611.17539](https://arxiv.org/abs/2611.17539) · [X 早报 11/19](https://binnn.top/x-brief-2026-11-19-am/)

### C3 · Ambient SFT：微调时别把预训练那点知识洗掉，最高提升 21%

SFT 的老问题是数据太少：几万条样本对上一个在万亿 token 上训过的底座，容易"学得会格式、忘掉世界"。arXiv 提出 **Ambient SFT**——把冻结的预训练模型当"高温噪声教师"，要求微调模型在高温分布下与它做**粗粒度对齐**，而不是逐 token 贴住。

实验结论：领域适配、指令微调、推理任务三类都优于标准 SFT，平均相对提升最高 **21%**。关键在"粗粒度"——约束整体分布形状，不约束具体措辞，既压过拟合也留住尾部知识。

**⚡ 跟你**：如果你动过"拿 200 篇自己写的东西微调写作风格"的念头，这是理论依据：小样本硬拟合必然丢味道。真要试，先接受"约束分布而不是背样本"。

来源：[AI 日报 11/19（arXiv）](https://segmentfault.com/a/1190000048406313)

### C4 · Spool：不改模型，只改缓存，流式视频首字延迟砍到 1/6.6

混合视觉语言模型（含线性循环层）在滑动窗口视频推理时有个结构性浪费：每来一帧，历史帧都要重算。arXiv 的 **Spool** 是免训练方案——缓存每帧的状态变换，配专用数据结构和 GPU kernel，在**不回放骨干网络**的前提下精确移除过期帧状态。

规模：5 个开源混合 VLM、4 个视频基准、20 组测试。p95 首字时间（TTFT）几何平均缩短到约 **1/6.6**（降约 85%），平均准确率还涨了 **2.3 个百分点**——通常加速要拿精度换，这次没换。

**⚡ 跟你**：做实时摄像头或视频理解 demo，**首字延迟就是体验生死线**。这类"不动模型、只动缓存"的工作最该抄——不用重训、不用换硬件。

来源：[AI 日报 11/19（arXiv）](https://segmentfault.com/a/1190000048406313)
