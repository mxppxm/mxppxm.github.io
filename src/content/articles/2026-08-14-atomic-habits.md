> 别再立 flag 了。习惯不是靠意志力养成的，是靠设计。

上周我给自己装了一个新 Skill：`atomic-habits`（原子习惯教练）。它不像普通的打卡 App 只会催你"加油"，而是把《原子习惯》那套方法论做成了 AI 能执行的完整流程——设计、戒断、复盘、生成可交互行动页，一条龙。

这篇文章不讲大道理，直接拆这个 Skill 是怎么工作的、能陪你做什么。

## 这是什么？

一个 AI 技能，让 AI 搭档变成懂行为设计的习惯陪练。你和它说话就像跟朋友聊天：

```
你 → 想每天读点书，但总是坚持不下来
AI → 先别急着定"每天读30分钟"。
     你之前是卡在哪儿？晚上刷手机停不下来？
     要不这样：今晚睡前，把书放在枕头边。
     等手机充电时顺手拿起书，翻开读一页就算完成。
     这周目标：完成 4 次，不要求天天读。
```

看到了吗？它不灌鸡汤、不列计划表，而是先找一个**真实诱因**，再给一个**两分钟能开始的最小行动**和**一周实验目标**。

## 核心能力

### 🎯 三种模式自动切换

Skill 会根据你说话的内容，自动选择工作模式：

| 模式 | 触发场景 | 它做什么 |
|---|---|---|
| **设计** | "想养成每天运动的习惯" | 找诱因 → 定两分钟启动动作 → 设一周实验 |
| **戒断** | "戒不掉睡前刷手机" | 找替代动作 → 反向四定律 → 写 if-then 预案 |
| **复盘** | "又破功了，跑了三天就断" | 诊断断裂点 → 只修一个环节 → 给最小改动 |

比如复盘模式，它不会说"你就是懒"，而是把问题归因到系统：

```
你 → 运动计划又黄了，坚持三天就断
AI → 先别自责，看看是哪一环断了：
     - 线索没出现？运动鞋收在柜子里，回家根本想不起来
     - 启动摩擦太大？"去健身房"这个开头太重
     - 奖励太弱？跑完没有任何即时反馈
     我赌是"线索没出现"——鞋放门口，回家一眼看到。
     今天先换鞋出门走 5 分钟就算完成。
     昨天没做也没事，今天别再断。
```

### 📐 四定律：不是知识，是检查清单

设计任何习惯，它都会用 James Clear 的四定律检查一遍：

| 定律 | 设计要点 | 例子 |
|---|---|---|
| **显而易见** | 线索要自然出现 | 书放枕头上、跑鞋放门口、App 放首页 |
| **有吸引力** | 绑定真实欲望 | "跑完步才能听那集播客" |
| **简便易行** | 两分钟就能开始 | "写文章" → "打开编辑器写一段" |
| **令人愉悦** | 完成立即有反馈 | 打卡、记一行、短暂休息 |

对付坏习惯则全部反过来：删掉 App、手机出卧室、零食放高柜——**增加摩擦，移除线索**。

### 🃏 生成可交互的习惯行动页

这是最有意思的部分。当你确认要开始执行，它会生成一张 **HTML 行动页**——不是海报，是一个能打卡的轻量陪练面板：

- **今天唯一的主行动**：打开页面 3 秒内就知道今天做什么
- **最近 7 天进度条 + 完成率**：完成就点一下，即时反馈
- **撤销功能**：点错了能撤回，不搞"连续天数"焦虑
- **"为下一次准备"**：一个客观、可立即完成的小动作，比如"把跑鞋放门口"，减少下次启动的寻找成本

核心设计原则：**完成是唯一必需的主入口**，不堆一堆没用的按钮。简单习惯就一个大按钮。

### 🚀 进阶教练模式

如果同一个习惯反复失败，它会自动升级为"进阶教练"，从 14 篇方法论文档里精准调用对应模块：

| 你的信号 | 它调用的模块 |
|---|---|
| "到底卡在哪" | 四阶段习惯诊断 |
| 总忘记、不知道什么时候做 | 线索绑定设计 |
| 正确行为太麻烦 | 环境摩擦设计 |
| 记得但就是不想做 | 吸引力重构 |
| 起步过猛、完美主义 | 最小可行连续性 |
| 回报太慢、打卡焦虑 | 即时强化反馈 |
| 被"我不是那种人"卡住 | 身份证据循环 |

比如你总忘记，它会用**习惯叠加**：`在 [已有的稳定动作] 之后，我先 [两分钟行动]`——"刷完牙 → 铺床""打开电脑 → 写一行今日计划"。

## 对话原则：先行动，后系统

Skill 最核心的一条原则是**不废话**。默认只输出四样东西：

1. 一句真实诱因（"再练一阵，拍照会更好看"而不是"你会成为更自律的人"）
2. 一句最小行动（"翻开书读一页"）
3. 一个触发点（"手机充电时"）
4. 一个本周过程目标（"完成 4 次"）

只有你要详细方案、打卡页面时才展开。它的文案检查清单里有一条很扎心：**"用户本人可能这样说吗？"**——凡是不像人话的鸡汤，一律不输出。

## 快速开始

想用上它，对你的 AI 搭档说这些词就会自动触发：

> 想每天运动但坚持不下来 · 戒不掉睡前刷手机 · 又破功了帮我复盘 · 生成一张习惯打卡页

如果你在用 Clacky，skill 已经装好了；其他 AI 平台可以把 skill 目录放进去重启即可。

## 设计哲学

一句话总结这个 Skill 的设计哲学：**把目标缩小，把设计做好**。

- 每天进步 1%，一年后是 37 倍——但它不让你想一年后，只想今天的两分钟
- 从不连续错过两次——错过一次就立刻规划下一次，别让破功变成"算了"
- 身份不是喊出来的——"我是一个跑步的人"是从每次完成里长出来的证据，不是页面上的标语

> 想深挖方法论？这套 Skill 的底层全部来自《原子习惯》四定律 + 行为设计研究，`references/` 里 14 篇文档就是完整手册。
