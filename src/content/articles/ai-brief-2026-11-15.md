### A1 ⚠️ 英伟达换帅：黄仁勋辞任，CFO 临危接管

11 月 12 日，英伟达董事会宣布**黄仁勋辞去总裁、CEO 及董事职务，立即生效**，由任职 13 年的 CFO **Colette Kress 出任临时 CEO**，并首次设立董事会主席（Harvey C. Jones）。Bloomberg 称导火索是「三段婚外关系报道，其中一位女性被怀疑为中国从事间谍活动」——此说来自媒体，官方公告只写「辞职」。

⚡ **跟你**：有项目押在 GPU 云或推理服务商上的话，这周去查一眼它的融资结构——上游金主换人，比模型涨价来得快。

### A2 Anthropic 双发 5.2：降价两成、快三成，还顺手「自我封印」了一项能力

11 月 9 日，**Claude Fable 5.2** 与 **Mythos 5.2** 同发。同源，差别在门禁：Fable 带网络安全与生物风险拦截、面向所有人；Mythos 解除部分限制，仅对通过官方验证计划的组织开放。价格 **8/40 美元每百万 token**（前代 10/50），输出快最多 **30%**。

⚡ **跟你**：别拿它当主力——26.5 美元一单会烧穿预算。它的用法是「卡住时请一次外援」，日常留 Opus 5.5 或便宜档。

### A3 Gemini 4 Hydrogen：快 2.5 倍，也贵了 15 倍

11 月 12 日，**Gemini 4 Hydrogen** 接替 3.8 Flash，主攻编码、文档处理和「要跑好几步」的 agent 任务，官方称默认档下完成任务**快 2.5 倍**。独立评测给了个微妙位置：Artificial Analysis 测出该档 **Intelligence Index 51 分**，而 3.8 Flash 高推理档只有 31 分，甚至比 Gemini 4 Argon 高推理档还多 1 分——一个 Flash 档的模型开始干中端推理的活。

定价 **1.5/7.5 美元**（缓存输入 0.075），Batch/Flex/Contributor 各半价，无首发优惠。VentureBeat 点破尴尬：**单价是最便宜一档的 15 倍**（Haiku 5.5、GPT-6 Luna、Muse Ember 均 0.1/0.5）。这等于明说：我卖的不是 token，是少跑几轮、少等几分钟。

⚡ **跟你**：「快 2.5 倍」对你真正值钱的地方是交互手感：等 40 秒和等 15 秒是两个产品。适合放在「人盯着」的环节，不适合后台批处理。

### A4 Meta 把价格打到 0.1 美元：专治「agent 一天调一万次工具」

同日发布的 **Muse Ember** 自称最小最省，定位不是答难题，而是 agent 一天重复一万遍的活：**工具调用、编码子任务、路由、抽取、长文档解析**。价格 **0.1/0.5 美元**（20 万 token 内），缓存输入低到 0.004，另给 100 万上下文与文本/图像/音频/视频输入。

独立坐标更清楚：**Intelligence Index 36 分，与 Claude Haiku 5.5 最高档持平，单任务成本约后者三分之一**——它是「拿到 36 分的最便宜模型」。容易被营销读糊的一点：**它不跟 Fable 5.2 抢活，抢的是主模型旁边那些跑腿的 subagent。** 一个 agent 系统里 80% 的 token 花在跑腿上，这才是它的杀伤半径。

⚡ **跟你**：流程里凡是「读网页→抽字段」「判断该调哪个工具」的步骤，整体换到这一档，主模型只留决策。这是立刻能省钱的一刀。

### A5 GPT-6 Cyber：先拿 Linux 内核开刀，再谈「对齐的黑客」

11 月 5 日，OpenAI 发布 **GPT-6 Cyber**——专门训练来找「可利用漏洞」并验证真伪的模型，官方强调**只在研究者设定的范围内行动**。它支撑了前一天的 Linux 内核安全研究，Mozilla、Palo Alto Networks、Cisco 已在试用，目前仅向 Daybreak Red 受邀者开放。

同一周微软安全团队给出完全相反的警报：**改不到 10 个神经元就能植入一个通过所有评测、只在触发词出现时才行动的 sleeper agent**，以及通过投毒微调劫持编码 agent 的「训练后供应链攻击」。两件事合起来才完整：**模型被训练成攻击者，和模型被悄悄变成内应，是同一个问题的两端**——而两端都长在你每天挂着的 agent 身上。

⚡ **跟你**：别随便给 agent 装来路不明的第三方 skill 或微调权重——那可能是你亲手请进项目里的内应。

### A6 ChatGPT 有了钱包：AI 帮你挑、帮你下单，指纹得你自己按

11 月 13 日，ChatGPT 加上 **Wallet**，由一个叫 **dots** 的 agent 负责「买什么」的决策与下单。首期限量给美国 Pro 用户，需满 18 岁、绑美国发行的 Visa/Mastercard/Amex。两个设计细节值得记：**卡号以支付令牌替代，不直接交给商家**；**结账前必须本人用 Face ID 或指纹确认**。

OpenAI 把「决策」交给 AI，把「授权」死攥在生物特征上——这是目前 agent 商业闭环里最务实的一条分界线。但风险不用回避：当 agent 能替你花钱，「它推荐什么」就开始有商业价值，而排序依据不会写在界面上。**这条线真正的监管问题不在支付牌照，在推荐透明度。**

⚡ **跟你**：「决策归 AI、授权归生物特征」这个切法，直接抄进你自己的 agent 设计：任何不可逆操作都必须有人肉闸门。

### B3 NVIDIA 亲自下场做「语义层」：89.7% 的星是这一周才涨出来的

周榜第三 `NVIDIA/auto-ontology`，一周 **9,327 星**、总星仅 **10,400**——**本周新增占 89.7%**：仓库 4 月就建好，这周才被大规模发现。Apache-2.0，仅 841 fork，README 明确暂不接受外部贡献。

它要解决的一句话很狠：**「一个收入指标答得再快，如果数字是错的，那也一文不值。」** 解法四步：Discover（从元数据生成企业本体）、Ground（给指标配可信业务含义、跨系统调和冲突定义）、Validate（用已认证定义与血缘校验查询，每个答案带出处）、Expose（经 MCP/CLI/API 分发给任何 harness，再把人肉修正回灌本体）。这是本周唯一大厂官方下场做 Agent 数据层的项目，反过来说明：瓶颈已从「模型够不够聪明」挪到「上下文够不够可信」。

⚡ **跟你**：你项目里那些「指标/字段到底什么意思」，恰是 agent 最容易答错的地方。给数据补一份可被 agent 读的字典，比再换个模型有用。

### C1 评测圈开始给 Agent 上刑具：幻觉分级、责任审计，还有「你能不能造出下一代 Agent」

这周 arXiv 上的东西比模型发布更值得看。11 月 5 日的 **MCPHallu**（2611.07689）第一次把 MCP agent 的幻觉拆成三层：**推理、执行、记忆**——以前只测「它说错了没」，现在要问「它是想错了、做错了、还是记错了」。

11 月 12 日又连发两篇：**ReA-Bench**（2611.16493）专测 agent 执行审计，针对「它已在本地云端自主干活、却没人能复核它干了什么」；**Singularity-Bench**（2611.16591）把题目设成「**Agent 能不能造出 Agent**」。11 月 11 日还有 **EvoX**（2611.15006），主张把 harness 当运行时策略重做。方向重合得太明显：研究界正从「让 agent 更能干」转向「让 agent 的可信度可被测量」。

⚡ **跟你**：这三篇给了你一套现成 checklist：出错时先分清是推理错、执行错还是记忆错——三种错的修法完全不同，混着改永远改不好。

### C2 Nature 这篇：一个 AI 原生的实验室，从头到尾没有人

《Nature》刊出**面向生物分子操作的 AI 原生自主实验平台**（s41586-026-11228-6）。摘要点的难点很具体：自主实验系统在化学与材料领域已有雏形，但**大多被锁死在「单一目标」框架里**，一旦要同时处理多目标、多步骤的生物分子操作就崩。这篇的贡献不是「又跑通一个实验」，而是把「AI 原生」落到工程上：调度、执行、观测、判断由同一套表征贯穿，人工干预降到最低。Altmetric 已到 144。

留个心眼：这类工作的评测口径历来模糊——「最少人工干预」到底是几小时？跨实验室能否复现？**摘要与正文均未给出跨机构复现结果**，所以它更像一个架构范式，不是可立即外包的实验服务。

⚡ **跟你**：「多目标、多步骤、无人干预」翻成前端就是一条长链路流水线：难的不是每一步，是让整条链共享同一套状态表征。

### C3 AI 当「机修工」：它能拆开另一个神经网络的内部看

《Nature》新闻版本月报道：研究者用一个 AI 模型去读取、并动手调节另一个 AI 网络的内部运作——这是可解释性第一次以「**用一个模型操作另一个模型**」的形态出现。为什么重要：过去理解模型靠人肉分析神经元和电路，一人一年能搞清的特征有限；如果「读内部」本身可自动化，**可解释性的产能就不再受人力约束**。

## 🎯 今天就能试的三件事

1. **World Labs 的 Atlas**：网页端与开发者 API 已同步开放，新用户送 1 万积分，一句话生成一个 3D 场景。有人实测一句话就搭出重庆山城——重点不是多真，而是这类能力已变成普通人直接能上手的产品。
2. **Gemini Decisions API**：单次最多评估 1000 个问题，直接给选项打分，延迟 150–250ms，输入 0.1 美元/百万 token、输出不计费。工具选择、政策检查这类有限选项决策，比让大模型自由发挥稳。
3. **给 agent 加一道死循环检测**：OpenRouter 在六个当前模型上实测四道防护——开启后六个模型都在第 3 次相同工具调用时被拦下，18 次运行有 16 次在两次真实调用后收尾；不开启时，有 4 次一直重试到 40 步上限。半小时能写完，省一整夜电费。
