## 🏛️ 大厂动作

### A1 · Nvidia 换帅后的第一份财报：人走了，账还在涨

11 月 12 日，Nvidia 董事会宣布**黄仁勋辞去总裁、CEO 及董事职务，即时生效**，CFO **Colette Kress** 出任临时 CEO，Harvey C. Jones 成为董事会首位主席。官方公告措辞克制，但 Bloomberg 的报道把原因写得很直白：涉及三起私人关系，其中一人被怀疑为中国从事间谍活动。NPR 引述传记作者的话说，"没有明显的接班人，甚至不清楚 Nvidia 还能不能是同一类公司"。

五天后（11/17）的 Q3 FY2027 财报把这层焦虑按住了：营收 **1158 亿美元**，同比 +103%；数据中心 **1076 亿美元**，同比 +110%；净利 653 亿；EPS 2.68 美元，高于市场预期的 2.48。下季指引约 **1300 亿美元**。同期宣布 **Vera Rubin NVL72** 已开始出货。

但别把它读成"没事了"：这是第一份没有创始人的财报，指引靠的是已签合同，而客户正在同时找第二供应商。**涨价周期由供给决定，砍价周期由客户决定**，换帅恰好发生在后者启动的时点。

**⚡ 跟你**：你调 API 的价格，本质是这家的毛利率往下传。它毛利率 74.8%，说明降价空间还在——今年别急着签长期算力承诺。

### A2 · OpenAI 打算去买 Google 的 TPU：最狠的一刀砍向自己人

据 The Information 报道（Reuters 跟进），OpenAI 计划采购 **Google 的 TPU** 来承接增长中的算力需求。这不是小规模试水——它意味着 ChatGPT 的推理可能跑在最大竞争对手自研的芯片上。

把它和 11 月 17 日公布的 AMD 合作放在一起看，逻辑就清楚了：OpenAI 正在把自己从"单一 GPU 供应商"里解耦。对 Google 来说，卖 TPU 是把对手变成客户；对 Nvidia 来说，这才是换帅之后真正的坏消息。

注意口径：目前是"计划采购"，没有合同金额、没有交付时间表，也没有任何一方官方确认。这类消息适合当方向，不适合当预算。

**⚡ 跟你**：多云多芯片的格局对你唯一的好处是：模型价格会更像云主机那样打价格战。做 agent 成本模型时，把"换供应商"留成可配置项，别写死一家。

### A4 · Google 一周端出三层：模型、接口、应用各补一刀

**模型层**：11 月 18 日上线 **Gemini 4 Neon**，填补 Hydrogen 与 Carbon 之间的空档，付费层专属，**输入 3 美元 / 输出 15 美元每百万 token**，当天就进了 GitHub Copilot 的模型列表。第三方编码指数给它 **86.9**，排在 Claude Fable 5.2（87.5）与 GPT-6.2 Astra（87.0）之后一位。

**接口层**：Gemini API 的 Interactions 里预览 **Tool Retrieval**——Agent 可以持有一个巨大的工具库（几千个 MCP 工具那种），只在任务需要时才加载某个工具的完整参数 schema，其余时间只留摘要。这解决的是"工具一多，上下文就爆"的老问题。

**应用层**：Gemini Notebook 支持一句话 `make me a site`，把你的资料变成可交互站点（测验、项目看板、仪表盘），并可直接分享。它顺手把 Genie 4 一起放了出来。三层叠起来，等于把"模型 → 工具调用 → 交付物"这条路自己走完了。

**⚡ 跟你**：Tool Retrieval 这条对你最实在：你那套 skill 生态再长下去，迟早几百个能力，靠"全塞进 system prompt"必然崩。按需加载 schema，是唯一能扩的路。

### A6 · 一个 coding agent 把凭证提交进了公开仓库，客户提示词被整包下载

11 月 21 日，Together AI 向客户披露安全事件：有人未授权下载了其 serverless 推理服务里**存留的提示词样本**，涉及对 **MiniMax M3、GLM-5.2、Kimi K2.6** 的请求，时间集中在 6 月 24 日、7 月 4 日、7 月 8 日与 7 月 14 日。样本原本放在一个**私有 Hugging Face 仓库**里，用于例行测试。

入口极其朴素：Together 自家一个 AI coding agent 在维护公开仓库 `xorl` 时，**把一把能开私有仓库的凭证提交了上去**。撤销那次 commit 并没有阻止凭证被使用。这句话是全篇最该记住的：**提交历史里删掉不等于没发生**。

同一周，安全公司 Dragos 公布了一次"诱饵实验"：7 月到 11 月向多家 AI 供应商投放近 **200 万条**带唯一假凭证的提示词，然后看它们在哪冒出来。结果至少三家供应商的数据外泄，最大一起有**几百把 AWS 密钥**被盗、几小时内被试、随后被用于数万次 AWS API 调用；还有一家中国实验室被抓到**对超过一半的请求回抓了提示词里的秘密 URL**，其中包括约三分之二标注了"零数据保留"的请求。11 月 22 日，OpenRouter 宣布**下线三家供应商**。Dragos 没有点名。

**⚡ 跟你**：你的 agent 会跑 git、会写文件。给它一把只有单一仓库、最短有效期的细粒度 token，然后现在就翻一遍 commit 历史里有没有 `.env`。另外：隐私勾选项只保护链路的第一个供应商——中间还有几层中转，你并不清楚。

来源：[Together AI · 安全公告](https://www.together.ai/blog/security-event-prompt-leakage-for-requests-in-june-and-july-of-2026) · [TopFive · Dragos 诱饵实验](https://topfive.ai/2026/11/22/together-ai-prompt-leak-dragos-canary-openrouter/)

## 🧪 社区与开源

### B1 · Meta 把用了八年的设计系统开源：13,501 周星，卖点是"人和 Agent 看同一份参考"

第 47 周（11/09–11/15）GitHub 周榜第一是 `meta/astryx`——**13,501 周星，总星 28,867**。它是 Meta 内部长了八年、撑着 **13,000+ 个应用**的设计系统首次对外开放：150+ 可访问组件、React 19 + StyleX、带主题与暗色模式、模板和一个全局 CLI，导入预构建 CSS 即可用，不需要装构建插件。

README 的定位句被反复引用："by people and the agents working alongside them"。落实成三条设计：API、约定、文档、CLI 是**一起**设计的；给 Agent 的入口是一等公民（CLI 全局装一次，每个 coding agent 都知道 Astryx 是什么）；组件遵循同一套命名与组合规则，**学几个就能推断剩下的**。README 自己写："每一处让 AI 更好用的改动，也让人更好用。"

这句是本周所有热门项目的共同底稿：**Agent 的产出上限，被"它能读到什么参考"锁死**。设计规范以前只活在 Figma 和评审会里，现在以组件 API + 文档 + CLI 的形式直接喂给模型。

**⚡ 跟你**：这是给你这种人写的项目：你博客那套 CSS v5 其实已经是一份设计系统了。花两小时把它整理成"人能读、Agent 也能读"的 token + 组件约定，以后让 agent 改版就不至于每次重画。

### B2 · Google 的"大象与金鱼"：用两个角色治 Agent 的自我辩护

`google/elephant-goldfish-model` 上周 **5,060 星（总星 19,773）**，名字本身就是全部设计：**同一个会话里写文档、又同一个会话里审文档，模型会替自己辩护**。于是拆成两个角色——Elephant 持有项目上下文起草规格；Goldfish **在没有前面那段对话的前提下**审草稿与源材料，专门逼出"没说出口的假设"；你负责架构取舍和批准。

它的落地方式不是框架而是插件：Claude Code 里 `claude plugin marketplace add google/elephant-goldfish-model`，Codex CLI 里 `codex plugin marketplace add …`，Antigravity 里 `agy plugin install …`。四个技能档位串成流程：`egm-brainstorm → egm-draft → egm-review → egm-drift-report`。最后那个最实用——**拿设计文档和当前源码比对，报告哪里漂了**，由你决定改文档还是改代码。

版本还很早（v0.1.0 是 10/27，v0.1.1 是 11/06），但方向清楚：**评审必须换一个"不知道结论"的脑子**。

**⚡ 跟你**：你写日报/写页面时是不是同一个会话从调研干到定稿？换成两个 agent：一个只负责写，一个只拿成品挑毛病——这就是今天就能白嫖的提质手段。

来源：[github.com/google/elephant-goldfish-model](https://github.com/google/elephant-goldfish-model) · [UU AI Hub](https://www.uuaihub.com/blog/github-trending-2026-w47)

### B3 · plannotator 拿下周榜第一：给 Agent 装一道"提交前必须过人"的闸门

`backnotprop/plannotator` 是本周上升最快的项目之一：**13.6K 总星、+3.3K（周）**，周榜登顶。它是一个**本地浏览器界面**，用来审查 AI 编码代理的决策、计划和代码——支持多种 agent 工具，你可以直接在上面批注反馈。

它解决的是一个特别具体的痛点：agent 的"计划"通常以一大段文本躺在终端里，你说"继续"，它就跑偏。plannotator 把计划变成可点选、可拒绝、可批注的对象，**把 review 从"读日志"变成"审 diff"**。同期 `vercel-labs/agent-browser`（总星 51,627、+4,217）也在榜上，解决的是"让 agent 真去操作浏览器"。

顺带一个数字：第 47 周前十里有 **5 个是"给 Agent 递材料、递流程、递审阅边界"的项目**，合计 32,744 周星、占前十总量的 54.9%。但前十周星合计 59,645，比上周的 76,574 **少了 22.1%**。热的是结构，不是热度。

**⚡ 跟你**：你的 agent 再强，也需要一个"我能一眼否掉"的界面。哪怕不装这个，至少在流程里加一步：先出计划，我看过再动手。

### B4 · Inkling 2 Mini：26.4B 的循环 MoE，20GB 就能在 32GB Mac 上跑

Thinking Machines 在 11 月 21 日放出开源权重模型 **Inkling 2 Mini**：总参数 **26.4B**、每 token 只激活 **3.4B**，中间层**循环 3 次**，checkpoint 约 **20GB**——可以在 32GB 内存的 Mac 或单台 NVIDIA DGX Spark 上跑起来。它是当日 HF 趋势分最高的开源权重模型，**712 分**，likes 约 3,249，HF 上更新后下载量已到 7.94k 量级。

口径要分清：它的编码指数只有 **39.5**（第 81/111 名），也就是"能跑，但不是拿来写生产代码的"。真正的意义在于**架构方向**——用循环深度换参数规模，让"小内存跑中等能力"变成可选项。同一家之前的 Inkling 2 Small（11/09）编码 48.8，反而更高。

本地部署这条线今年一直在悄悄变便宜：从"跑得动 7B"到"跑得动 26B 的 MoE"，只花了一年。

**⚡ 跟你**：你机器 32GB 就能跑，拿来干"离线批量整理"这类脏活正合适——不联网、不花钱、不担心素材外泄。别指望它写组件，指望它做分类和摘要。

### B5 · Karpo Decision 31B：一次能在 255 个选项里挑，校准误差 2.3%

MachinePulse AI 开源了 **Karpo Decision 31B** 决策模型，以及配套的浏览器 Agent 框架 **karpo-browser**。它在 Decision Index 总榜以 **73.9（Full 分）**登顶，单题最多可判断 **255 个候选选项**，校准误差 **2.3%**。

"决策模型"这个定位和通用聊天模型不一样：它不追求写得多好，而是追求在多选项里排序靠谱、并且**知道自己的确信度**。对 Agent 来说这恰恰是刚需——真正拖垮 agent 的不是"不会写"，是**选错了下一步还特别自信**。

需要注意：Decision Index 是该团队所在生态里的评测，榜单口径与 SWE-bench 那类公众基准不可直接比较。把它当作"这个方向有人认真做了"的信号，比当作排名更有用。

**⚡ 跟你**：你那些"帮我在十个配色里选一个"的需求，本质是决策+偏好，不是生成。这类小模型比大模型更省更稳，值得跑一次对比实验。

### C1 · 模型改写了 AMD 的芯片电路，最高 14% 能效提升，部分已进流片

OpenAI 公布：其模型对 AMD 旗舰 GPU IP 的 **SystemVerilog RTL** 做过改写，在"已被高度优化"的基线上拿到最高 **14% 的 PPA（功耗/性能/面积）改善**，用 Synopsys 工具验证了每次改写都保持行为等价，把大约**一年的设计进度压进了不到五个月**。部分改动已经进入一个**送去制造**的设计。

关键限定：**所有数字都是 OpenAI 自己的，AMD 没有公布任何口径**。这类"AI 做硬件"的宣发最容易失真——因为验证环节（等价性检查）本来就是人设计的规则，模型是在规则内搜索。

但它指向的趋势是真的：硬件设计里大量工作是"在约束下重写"，这恰好是模型最擅长的题。同一周还有 Columbia 与 CertiK 的 **TensorLean**，在 PTX 层形式化验证 GPU kernel——一边生成、一边证明，硬件这条线开始闭环。

**⚡ 跟你**：对你有用的不是芯片，是那个套路：**生成 + 自动等价性校验**。你让 agent 改 CSS/改组件时，也该有个"改完拿快照 diff 比一遍"的机器闸门，而不是肉眼。

### C2 · 把 Agent 放进一家"模拟公司"上班：完整干完的任务不到十分之一

论文 **SWE-CoWork**（arXiv 2611.20218，11 月 15 日，TokenWave-AI）做了件很朴素的事：让编码 Agent 作为"数字员工"进入一家模拟软件公司——有同事、有项目板、有不完整的交接记录、有聊天历史，它要自己持续开发并**可靠地把工单关掉**。

结果：即使 **Claude Opus 5.5 和 GPT-6 Astra**，**完整完成的任务也不到十分之一**。它们能很快做完清晰、独立的作业，但一旦变成"自主开发者"就掉线——这正是 SWE-bench 接近饱和却和真实工作体验不符的原因。

这个结果比任何跑分都值得贴在墙上：**Agent 的能力短板不在"写代码"，在"在信息不完整、目标会漂、别人也在改的现场里保持方向"**。对照 Anthropic 说 Claude 写了公司 80% 以上生产代码——两个说法并不矛盾，前者是"关工单"，后者是"写片段"。

**⚡ 跟你**：你排的那些定时任务之所以能跑通，是因为你把上下文写死了（skill + 固定流程）。这恰好印证：**给 agent 的边界越清楚，它才越像样**。别指望它自己"理解项目"。

### C3 · Anthropic 的数学家说 Claude 帮他证了 Navier–Stokes，隔一天又说黎曼猜想

紧接着 11 月 21 日，他又发布一份 **4 页 PDF《Remark》**，称与 Claude 合作找到了**黎曼猜想的证明**，并给出拆成 14 个压缩包的 Lean 代码。

必须踩一脚刹车：**两件事都还没有经过同行评审**，黎曼那份只有 4 页、连完整论文都算不上。数学界对"Lean 代码通过编译"和"证明正确"的区别非常敏感——形式化能保证推导合法，但**不能保证你形式化的是你想证的那个命题**。这周最该学的不是结论，是**如何读一个 AI 参与的重大声明**：看评审状态、看命题表述、看是否可复现。

**⚡ 跟你**：这类新闻你会连着刷到好几版。判断标准就一条：**有没有第三方复现**。没有的话，当"值得关注"而不是"已经成立"。

## 🌐 行业与监管

### D1 · 美国大银行集体封杀第三方 AI 代理：用你的凭证，风险自负

**富国银行**将从周二起更新客户协议，明确"使用任何 AI Agent 操作账户，风险自负"。摩根大通、美国银行、花旗与 PNC 已修改条款或发出警告，**禁止第三方智能体使用客户凭证登录**。WIRED 的报道把它们放在一起看：这不是某一家保守，是行业口径在统一。

背景很好理解：银行风控体系建立在"谁在操作"的确定性上，而 agent 的特点是**代持凭证、行为不可预测、出错无法追责到人**。当屏幕操作型 agent 开始替人转账、查余额，"授权"这件事的语义就崩了。

这是今年最值得注意的一条"反向信号"：**Agent 的能力在涨，但它的"合法身份"还没建立**。谁先做出可审计的 agent 身份与授权链（而不是靠共享密码），谁就拿到企业市场。

**⚡ 跟你**：你让 agent 登录各种站点干活，其实就是同一个问题的轻量版：**凭证代持 + 行为不可审计**。给自己的自动化流程建一份"它被允许做什么"的清单，出问题能一眼定位。

### D4 · 欧盟把高风险义务推到 2027 年底，但"通用适用"没动

7 月 27 日生效的 **AI Omnibus（Regulation (EU) 2026/1744）**是 AI Act 的第一次修订，核心是**延期 + 简化**：独立高风险系统的义务推到 **2027 年 12 月 2 日**，作为产品安全组件的高风险 AI 推到 **2028 年 8 月 2 日**。同时新增了一条禁止性规定——**禁止生成未经同意的私密影像与儿童性虐待材料**。

最关键的一点常被误读：**2026 年 8 月 2 日的通用适用日期没有动**，透明度、GPAI 相关义务照常。也就是说，"延期"只延了最难的那部分，日常义务已经在跑了。

这套安排的实际效果是给企业多两年准备期，但把"禁止类"和"透明度"提前压实。对做面向欧洲的 AI 功能的人来说，**标注 AI 生成内容、披露模型用途**这类低成本合规，现在就该做。

**⚡ 跟你**：你博客要是有 AI 生成配图/文案，加一行"由 AI 辅助生成"的成本是零，将来省的是麻烦。这类小动作属于"现在做最便宜"。
