## ① 大厂动作

### A1 · GPT-6.1 Terra 把"会看屏幕"变成日用品，价格砍一半

10 月 26 日 OpenAI 发布 `gpt-6.1-terra`，ChatGPT Work、Codex、API 同步上线，标准 API 价格比 GPT-5.6 Terra 与 GPT-6.1 Sol **低 50%**。微软 Foundry 同天 GA，短上下文档位标价 **输入 1.00 美元 / 输出 1.25 美元（每百万 token）**。

定位很明确：不是最聪明的那个，而是"每个工作日都能用得起"的那个。官方强调它理解屏幕上有什么、能跨应用点按钮、写东西更自然——本质是把 **computer use 从演示推向批量任务**。

要注意口径：OpenAI 自己的系统卡附录写的是"与近期的 GPT-6、GPT-6.1 系列表现相当"，也就是说**能力持平、价格腰斩**才是这次的真实卖点，不是又一次智力跃迁。

**⚡ 跟你**｜你那套"让 agent 自己点页面验收"的前端流程，终于到了可以天天跑而不心疼账单的价位——批量截图巡检、点按钮回归测试，都可以排进定时任务了。

来源：[OpenAI 官方](https://openai.com/index/introducing-gpt-6-1-terra)（10/26）· [SiliconANGLE](https://siliconangle.com/2026/10/26/openai-launches-gpt-6-1-terra-for-faster-better-performing-ai-agents-at-half-the-price/)

### A2 · Genie 4 会给世界配音了：能走进去、能听见、还能用嘴改剧情

10 月 27 日 Google DeepMind 发布 **Genie 4** 研究预览，第一次让实时世界模型**原生生成音频**——音乐、环境声、对话一起出来，而不是后期贴音轨。画面由 Gemini Omni 锚定真实质感，**Gemini 3.8 Flash** 在回路里当引导代理，把你的目标拆成一步步动作。

交互方式也变了：过去是"生成一段视频"，现在是**你走进去、用自然语言改剧情**，场景会实时响应你的移动，里面的人会动、会反应、会说话。

官方自己泼冷水：这是"早期实验模型"，先开 waitlist，随后向开发者与 Google AI Ultra 订阅者开放。**别指望现在就拿它做生产资产**。

**⚡ 跟你**｜对做创意页面的你，这意味着"氛围"第一次可以被实时生成：鼠标一推、环境声跟着变。先想清楚交互脚本，等它开放那天你就是有准备的人。

来源：[Google DeepMind](https://deepmind.google/blog/genie-4-a-new-generation-of-world-simulation)（10/27）· [TechCrunch](https://techcrunch.com/2026/10/27/googles-genie-4-world-model-adds-audio-more-realistic-worlds-and-real-time-steering)

### A3 · Anthropic 买了一家"一个人"的药企，然后把 Claude 派去当科学家

10 月 27 日 Anthropic 宣布收购 **Mithril Medicine**——一家只有一名员工的罕见病生物公司。创始人 Cody Tranbarger 用 Claude 管合同、物流、实验排期，协调 **11 家外部实验室**，把一款肌营养不良抗体候选药从概念推到小鼠体内验证，只花了 **18 个月**。

同一天它还公布 Claude Science 研究工作台，并与百时美施贵宝、Generate Biomedicines、BigHat、Divergence、Enveda 等六家机构合作，覆盖 CAR-T 增强、抗体片段、实体瘤与食物过敏。

分歧点在于证据强度：技术报告日期是 10 月 26 日，**明确标注未经同行评审**，公司自己说可能的人类临床试验时间是 2028 年底。这是"一人公司"叙事的漂亮样本，但还不是临床结论。

**⚡ 跟你**｜真正值钱的是那个结构：一个主编排人 + Claude 当项目经理 + 外部产能按需接入。你手上的个人项目（画室、日报流水线）已经是同一个模子，缺的不是能力，是"外部产能"那一环。

**⚡ 跟你**｜你在终端里跟 agent 拉扯的那些活（构建、截图、部署），正好是它的强项。等权重落地，本地跑一个当"截图验证专员"比调 API 更省心。

### A5 · "Le Chonk"按时开闸：欧洲把 1T 参数的开源权重摆上了货架

Mistral 10 月 6 日预告的 **Mistral Large 4**（外号 le Chonk）按承诺在 10 月 27 日放出权重：**1.05T 总参数、52B 激活**的 MoE，原生多模态，带 1.6B 视觉编码器，1M 上下文档位。Hugging Face 模型卡上周还挂着"即将发布"的倒计时。

它的战略意义大于参数意义。CNBC 的定性是：这是欧洲对"中国开源阵营"最正面的一次回击——过去一年最强开源权重几乎都出自中国实验室，Mistral 需要一个能摆在同一个货架上的东西。

现实提醒：1T 总参数意味着就算按 4bit 量化，也不是普通机器能吞下的规模；面向企业的实际形态仍然会是 API 和托管部署，**"开源"在这里约等于"可自托管"而不是"可笔记本运行"**。

**⚡ 跟你**｜你不需要本地跑它，但需要知道货架上多了一款非中国、非美国的选项——做客户项目时，"数据不出欧盟/不出境"这类合规话说出口，背后得真有模型可选。

来源：[Mistral 官方](https://mistral.ai/news/mistral-large-4)（10/06 预告）· [CNBC](https://www.cnbc.com/2026/10/06/mistral-ai-model-le-chonk.html)

### A6 · MCP 生态出了个 9.3 分的洞：不用登录就能读你整台机器的文件

10 月 26 日披露的 **CVE-2026-93328**（CVSS 9.3）打在 Google Cloud 的 **MCP Toolbox for Databases**（`googleapis/mcp-toolbox`）1.2.0 至 1.4.0 上：cloud-storage 数据源同时存在路径穿越与鉴权缺失，**未认证的远程攻击者**可以读走宿主文件、也能覆盖写入，并把内容外传到攻击者自己的 GCS 桶。

同一天还有一条更狠的：**MLflow** 3.12.0rc0–3.17.0 的 **CVE-2026-116692**（CVSS 9.8），评分器反序列化允许请求方指定模块后代而非精确匹配，未开鉴权的部署可直接被 RCE，修复版本 3.17.0。

这两条放在一起看才刺眼：我们正在给 agent 越来越多的"手"，而给这些手上锁的速度，明显慢于装手的速度。

**⚡ 跟你**｜你机器上跑着不止一个 MCP server，凡是接数据库或云存储的，今天就去 `pip show` 看一眼版本；顺手给自己立条规矩：MCP 只给最小目录权限，别让它看到 `~/.ssh`。

来源：[CVE 记录](https://cvefeed.io/vuln/detail/CVE-2026-93328)（10/26）· [AI Weekly 安全警报](https://aiweekly.co/ai-news-today/)

### B1 · 一个"反 AI 味"的设计 skill，一天涨了 2244 星

`Nutlope/hallmark` 昨天站在 GitHub 日趋势第 1 位：**37.2k 总星、单日 +2,244、涨幅 6.4%**。它干的事很具体——给 Claude Code / Codex / Cursor 装一套"拒绝看起来像 AI 生成"的设计规则，安装只要一行 `npx skills add nutlope/hallmark -g`。

它的做法不是"多给几个配色"，而是**先设计、后写码**：先读你的 design token，再出结构，最后过一遍 58 项检查清单。作者的原话是"两遍是正常的；三遍说明 brief 错了，不是设计错了"。四个命令：build / study / redesign / audit，其中 study 能从截图或 URL 里反推出主题。

**⚡ 跟你**｜你就是干这个的——直接装上，然后拿你自己那份"单文件 HTML 日报"当试验田：让它的 linter 挑一遍毛病，看它能不能说出你一直觉得别扭但说不出哪别扭的地方。

### B2 · Anthropic 把 Claude Code 的沙箱开源了，Apache 2.0，三平台通吃

10 月 24 日，Anthropic 以 **Apache 2.0** 开源了 Claude Code 用的 `sandbox-runtime`，Linux、macOS、Windows 全支持。这东西的价值在于它是"**跑 AI 写的代码时，怎么保证它动不到不该动的东西**"的现成答案。

时机值得玩味：正好压在 MCP Toolbox 的 9.3 分漏洞披露前两天。一边是生态里冒出来的新洞，一边是把自家隔离层交出去——这不太像巧合，更像是"我们知道这是瓶颈"。

对个人开发者更实际的意义是：你终于不用自己拿 Docker + seccomp 手搓一套围栏了，尤其是本地跑 agent 干"读文件、装依赖、跑测试"这类脏活时。

**⚡ 跟你**｜你那些让 agent 自己跑 `git push`、自己截图、自己改文件的流水线，最怕它手滑。把这层套上，等于给它戴了手套——出事只脏手套，不脏手。

### B4 · 给 agent 装一双"看全网"的眼睛，不花 API 费

`Panniantong/Agent-Reach` 昨天 **104k 总星**、单日 +746。一句话概括：一个 CLI，让 agent 去读 Twitter、Reddit、YouTube、GitHub、B 站、小红书——**零 API 费用**。

它踩中的是真痛点。模型再强，读不到东西就是空转；而各家平台的 API 要么收费、要么限流、要么干脆不开放。社区绕过去的方式就是"用浏览器能看到的，agent 也能看到"。

风险也直接写在脸上：这条路必然踩平台条款，且网页结构一改就断。**当一次性侦察工具可以，当生产依赖要三思。**

**⚡ 跟你**｜你的日报流水线现在靠搜索引擎 + 手工抓页，这条正好补上"社区一手素材"——GitHub 涨星、小红书审美风向，都是你文章里最缺也最鲜活的那部分。

### B5 · NVIDIA 做了个"skill 安检机"：装之前先扫一遍有没有夹带

`NVIDIA/SkillSpector` 昨天 **22.5k 星**、+214。它扫的是 Claude Code / Codex / MCP 的 **skill 包**：漏洞、恶意模式、提示词注入、数据外传、供应链风险——官网原话是"在你安装之前"。

这个方向出现得正是时候。skill 生态现在长得像早期 npm：任何人可以发、任何人可以装、没有任何审核。`npx skills add` 一行就装进来的东西，**实际权限等于你给终端的权限**。

它不解决根本问题——静态扫描永远追不上新手法——但它把"默认安装"变成了"安装前有一次判断"，这在生态早期已经是巨大的一步。

**⚡ 跟你**｜你自己就在写 skill。工具反过来也能当写作者的自检清单：现在先照它的检查项过一遍你手上的 skill，顺便想清楚"我这个 skill 会读哪些目录、会发什么请求"——这问题迟早有人问你。

## ③ 研究前沿

### C1 · Hugging Face 放出一个"能跟 DNA 对话"的开源模型，笔记本就能跑

10 月 22 日 Hugging Face 发布 **Carbon-X**：以 Qwen3-14B 为底座、约 **14.8B 参数**，用 **3,020 亿 token** 的 DNA 序列、英文文本与生物学材料混合训练，让遗传密码和自然语言落在同一个表示空间里。

用法很朴素：把一段序列丢进去，问"这个突变可能意味着什么"，它用平实的英语解释自己的判断——**可分析、也能生成序列**。合作方包括意大利与中国的实验室，权重开放，官方称可跑在单张 80GB 卡上，Wired 的表述更激进：能在笔记本上本地运行。

边界要划清楚：它不是测序仪，不会碰试管，本质是"序列上的语言模型"。医学结论仍然要人来做，但"问一句就懂"这件事本身，已经改变了生信的门槛。

**⚡ 跟你**｜可复用的是范式不是领域：小模型 + 大量领域 token + 自然语言接口，就是把"专业数据"变成"能聊的东西"。你的审美库、设计 token 库，完全可以照这个配方做一个小模型。

来源：[WIRED](https://www.wired.com/story/hugging-face-new-ai-biology-model-chat-with-dna)（10/22）· [TNW](https://thenextweb.com/news/hugging-face-carbon-x-dna-ai-model)

### C2 · 上海 AI 实验室给长思维链 RL 配了个"在岗评审"，从 1.5B 一路撑到 397B

10 月 27 日的预印本 **S3AC** 解决的是长思维链强化学习里一个很实际的问题：过程奖励模型（PRM）通常得固定在某个规模上训练，换了模型尺寸就不准了。他们的做法是训一个 **working critic**——随策略一起演化的评审，并用**提示难度采样**来喂数据。

可扩展性是重点：从 **1.5B 一直做到 397B**，同一套评审机制不用重训。这意味着"过程监督"从论文里的玩具，开始变成大模型后训练的常规零件。

注意：这是预印本，尚无独立复现；而过程奖励本身有已知风险——评审偏了，策略会学着讨好评审而不是变聪明。

**⚡ 跟你**｜这套"边训边评"的思路，你其实在 agent 流水线里手工做过：让另一个模型给自己打分。区别是人家把评审做成了可扩展组件——你的 skill 生态也该有个固定的"验收员"角色。
