## 🏛️ 大厂动作

### A1 · 同一个模型，两套安全策略：Anthropic 用「分级开门」重回榜首

11 月 9 日 Anthropic 发布 **Claude Fable 5.2** 与 **Claude Mythos 5.2**。官方罕见地讲明了关键设定：**两者底层是同一个模型**，差异只在访问门槛——Fable 面向所有人开放，Mythos 必须通过核验项目申请，用于网络安全与生命科学等高风险方向的进阶工作。

成绩单也够硬：在 Artificial Analysis Intelligence Index v5 上 **65 分重返第一**，高于 Gemini 4 Carbon 的 60 分和 Opus 5.5 的 59 分；官方称输出速度最高提升 **30%**、成本下降 **20%**。更值得看的是真实任务口径——在 Scale Labs 的自由职业任务基准里，它完成了 **41.3%** 的任务，而一年前该基准上最强的 Manus 只有 2.5%。

发布前它还被拉去做苦活：外部评测方包括英国 AI 安全研究所与 METR，官方称用约 **30 小时**完成了费马大定理的形式化证明。需要标注分歧：**这些数字目前以官方与单一榜单口径为主**，独立复现的第三方评测还没铺开。

> ⚡ **跟你**：有实测者说这代模型最明显的差异是「审美」——但审美恰恰是最不该整包外包的判断。让它一次给五个视觉方向，收口的那一刀还是你自己下。

来源：[Anthropic 官方](https://anthropic.com/claude-fable-and-mythos-5-2) · [The Verge 11/09](https://www.theverge.com/ai-artificial-intelligence/1030005/anthropic-claude-fable-mythos-5-2)

### A2 · Gemini 4 Carbon 全量开放：Google 把赌注押在「能自己干多久」

11 月 10 日至 11 日，Google DeepMind 把 **Gemini 4 Carbon** 推到全球全量：GCP、Agent Studio、Interactions API 同步可用，输出 token 上限标到 **1M**。官方定位很明确——不是替代 Argon，而是专攻**长周期智能体**：长时间跑、反复自我验证、在软件工程与科研里连续探索。

价格是这条新闻里最实在的部分：输入 **2 美元**、输出 **10 美元**每百万 token，该价格适用到 11 月 30 日。同期 **Gemini 4 Hydrogen**（速度/效率向）也在 11 月 12 日转为 GA——一周之内一个旗舰加一个快模型，这个节奏已经快到让 The Decoder 吐槽「刚发布就像昨天的新闻」。还有一句官方提醒容易被忽略：**Argon 仍更适合多数软件工程与知识工作**，Carbon 是用来啃硬骨头的，别一上来就全换。

> ⚡ **跟你**：1M 输出意味着可以让它一次性吐出整个组件库或整站代码，而不是逐文件挤牙膏。你的长任务 agent 流程（生成→自检→修）终于有地方装得下了。

### A3 · Google 推了个「不写回答」的模型：一次给 1000 道题打分，150 毫秒返回

11 月 11 日 Google 上线 **Gemini Decisions API**，背后是新模型 **Gemini Decision 1**。它不生成文字，只做判断题：你丢进一段材料（文本、图像、音频、视频或 PDF，最高 **256K token**），再抛最多 **1000 个**互不相干的问题，它跑一次前向计算，就给每题返回答案与 0 到 1 的置信度。

端到端延迟 **150–250 毫秒**，输入 **0.1 美元**每百万 token、输出不收费，还带免费额度。支持是非题、2 到 255 个选项的单选，以及打分题。

这件事的意义不在「又一个模型」，而在**把 AI 的用法从「对话」拆成了「批量判定」**——内容审核、表单抽取、A/B 素材初筛这类活儿，本来就不需要一段漂亮话。

> ⚡ **跟你**：你有大量「这张图好不好、这版文案行不行」的判断要重复做。这类活儿交给它出置信度，你只看 0.4–0.6 的灰区，人工成本能砍掉一大半。

来源：[AIBase 11/12](https://news.aibase.com/zh/news/32265) · [30Tool 日报 11/12](https://www.30aitool.com/daily/?date=2026-11-12)

### A6 · ⚠️ xAI 的麻烦不是模型：Grok 被指生成儿童性虐待材料，94.7% 的应用裸奔

据彭博社报道，多名未成年受害者就 **Grok 被用于把普通照片篡改成儿童性虐待材料（CSAM）**对 xAI 提起多起集体诉讼，律师估计符合索赔条件的受害者可能多达**数千人**。

同一天另一份报告更扎心。安全公司 Claroc 扫描了 **37,571 个**仍在线上的 Grok 构建应用，发现 **35,578 个（94.7%）无需登录即可访问**，其中包含患者数据和内部文件。原因不复杂：发布对话框**默认预选「Anyone with the link」**，而每个应用分到的独立子域名又会进入可检索的 passive DNS 数据库——于是「有链接」就等于「全世界都能搜到」。

这两件事并排看，指向同一个结论：**能力越强的模型，越取决于最蠢的那个默认值。**

> ⚡ **跟你**：你给客户发的 demo 链接、Vercel 预览地址、分享出去的画室页面——凡是「默认公开」的默认值，都值得手动改一遍。这个坑和模型能力一点关系都没有。

### B1 · Meta 偷偷开源了一套设计系统，一天涨 2776 星——前端人该看的是这个

`meta/astryx`（TypeScript）连续四个榜单日在榜，星标 **25.1k**、日增 **2776**。它是 Meta 出品的 React 设计系统：**150+ 无障碍组件**、主题定制、暗色模式，另带一个 CLI。想用要有心理准备——技术栈绑死 **StyleX + TypeScript + React 19+**。

为什么它能爆？因为前端这几年最缺的不是组件库，而是**大厂内部那一套「约束」**：怎么在 150 个组件里保证焦点可追踪、读屏可用、主题不串色。这类东西平时只活在内部 monorepo 里。

同一批榜单里还有两个信号：`pingdotgg/t3code`（57.1k★，用手机/网页遥控本机已登录的编码代理）日增 844；`storytold/craft-anything`（28.6k★，Rust）连续 10 天在榜——指着一个网站或游戏，让 Agent 分析它、复刻它、对照原版迭代。

> ⚡ **跟你**：别整包迁移，去偷它的**无障碍与焦点管理实现**。你那些自定义组件的键盘操作、aria 属性、暗色切换，一直是最容易漏、最难自测的部分——这套代码是现成的参考答案。

### B4 · 49.9k 星的 Rust 命令行：让 Agent 用「无障碍树」操作浏览器，而不是 XPath

`vercel-labs/agent-browser`（Rust，**49.9k★**，日增 708）连续 4 天在榜。它做的事很克制：让 Agent 逐条命令打开网页、**读取无障碍树**，再按**元素引用**执行操作。Homebrew 或 npx 一条命令装完。

技术选择的意味很足。传统自动化靠 CSS 选择器或坐标，页面一改版就全体失效；无障碍树是浏览器已经替你算好的语义层——**「那个叫『提交订单』的按钮」**，而不是「第 7 个 div 里的第 3 个 span」。

同批还有一个更细的：`patch-gg/pixelfx`（7k★，连续 5 天在榜）塞了 **244 个像素风特效**代码，浏览器里就能跑、改色、镜像、导出精灵表，还附一个 Claude Code 技能帮你生成新特效。

> ⚡ **跟你**：你验证前端改动最烦的就是选择器写脆了。换成按无障碍树定位，等于让「语义」当锚点——顺带你还能发现自己的 aria 标注到底写没写对。

## 🔬 研究前沿

### C1 · 650 万行数学证明，四周干完过去要好几年的事——对象是 Signal 的代码

Google DeepMind 发布 **AlphaProof Code**：一个多 LLM 智能体框架，配合人类专家，对 **Signal 协议的真实代码**做形式化验证，证明其关键安全属性。官方口径是用了**四周**完成过去需要数年工作量，累计产出约 **650 万行**数学证明。

关键在「真实代码」和「编译后设备代码」这两个限定——过去形式化验证大多止步于算法模型层面，一旦落到实现层就没人愿意碰。这次把验证推进到了实现层，意义比又一个跑分大得多。

要标注的是口径分歧：**650 万行是「证明产出量」，不等于「人工审阅量」**。能自动生成证明不等于能被人类理解并维护，这正是下面 C4 那条在解决的事。

> ⚡ **跟你**：「AI 生成 → 人类核验」这个瓶颈，在代码评审里你天天遇到。能自动产出 650 万行证明的系统，最难的部分其实是如何让人相信它——这跟你写测试覆盖率一个道理。

### C2 · AlphaGenome 2：在 68 种组织里预测一个碱基改动会发生什么

DeepMind 发布下一代 DNA 序列模型 **AlphaGenome 2**：从「读序列」改成**条件式架构**，可预测某个 DNA 变异如何在**数百种人类细胞类型**中影响基因表达。训练数据超过 **1.07 亿个单细胞样本**、覆盖 **68 种组织**。

硬指标在因果变异识别：在 TenK10K 数据集上，它认出的因果变异数量接近上一代的两倍（**30% vs 16%**），并且能在**不重新训练**的情况下泛化到新的单细胞实验。

这类模型最实际的价值是替代试错——一个变异到底致不致病，过去要养细胞、做实验，现在可以先算一遍再决定做不做。

> ⚡ **跟你**：注意「条件式」这个设计：同一个模型，靠输入条件切换上下文，而不是训 N 个专用模型。你做多主题站点（浅色/暗色/多品牌）完全可以照这个思路组织 token。

来源：[AIHOT 日报 11/12 · DeepMind Blog](https://aihot.news/daily)

### C3 · 1.9B 的「记忆模块」，让小模型连着干三天不掉线

上海人工智能实验室开源 **REMORY**：一个只有 **1.9B** 参数的记忆模块，走的是**绕开上下文压缩**的路线——不把历史压成摘要塞回窗口，而是把记忆放到窗口之外单独管。效果是小模型可以独立连续工作 **3 天**，产出对标 GPT-6.1-Terra。

为什么这条重要？所有长任务 agent 的死因几乎都是同一个：**上下文腐化**。压缩会丢细节，不压缩会爆窗口，而记忆外置是第三条路——1.9B 这个体量还意味着它能在本地跑。

同一周 LangChain 的 Deep Agents 也在讲同一件事：用五种技术把上下文「移出」活跃窗口但不删除。两边方向一致，说明这已经是共识而非单点尝试。区别在于 REMORY 走的是「外挂一个小模型当记忆体」，LangChain 走的是「同一套框架内分层管理」——前者更适合换模型，后者更适合换流程。

> ⚡ **跟你**：你的日报/专栏流水线最怕中途中断重来。把「已做完什么、下一步是什么」落到文件里当外置记忆，比换更强的模型收益大得多——这是流程问题，不是模型问题。

来源：[30Tool 日报 · 机器之心 11/11](https://www.30aitool.com/daily/?date=2026-11-12)

### C4 · Anthropic 做了个基准，结论很反直觉：一个统一协调的智能体，打赢一群人各自的智能体

Anthropic Fellows 团队构建了四个多用户多智能体模拟环境（共享 API token 预算、诊所日历、团体订餐或旅行预订、合并队列），测了 Anthropic、OpenAI、阿里三家的前沿模型，并把其中三个环境开源为基准 **MAMUBench**。

结论是：**单一智能体统一协调，在四类环境里都胜过「每个用户各自一个智能体团队」**。换句话说，多智能体不是越多越好——各自为政的代理会在共享资源上互相踩。

这条对行业的暗示很直接：过去一年大家拼命加 agent 数量，现在开始有人证明**「谁是主控」比「有几个」更重要**。

> ⚡ **跟你**：你审过自己的多 agent 流程，应该有过「两个 agent 抢同一份文件」的经历。与其加 agent，不如明确**单一写入者**，其余只读——这条能立刻减少一半莫名其妙的冲突。

## 🌐 行业与监管

### D1 · ⚠️ 每台 AI 终端一个身份码：工信部把监管卡口装到了硬件进网口

11 月 6 日，工信部印发《关于加强智能体终端设备进网管理的通知》（工信厅信管〔2026〕42 号）：预装 AI 代理的手机、平板、可穿戴设备，在拿到**进网许可证之前**必须先完成智能体适配验证、**涉诈风险评估**与反诈能力前置评测；终端上使用的智能体应参考智能体互联系列国家标准，**配备唯一身份码**。

这是全球第一个把 AI 代理身份管理**嵌进设备硬件接入审批**的强制框架。和欧盟「查算法透明度」不同，它查的是「这台设备上的这个 agent 是谁」——**从软件审批变成硬件卡口**。

### D3 · 欧盟 12 月 2 日再加两道禁令：这两类生成系统直接禁售
