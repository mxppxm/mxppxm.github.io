## 它是什么

一张悬浮在空中的 3D 元素周期表。118 张卡片按真实周期表布局排成一道弧，鼠标悬停弹出大字卡，点任意元素进入「剖析」：

- 中间是这个元素的玻尔原子模型，质子、中子按真实数量摆放，电子按壳层绕核运动，可以暂停；
- 左边是档案：原子量、族 / 周期、电子排布、特征发射光谱；
- 右边是物性、常见化合物和特征反应，可以放大看；
- 「结构 / 辉光」两种视图是两套渲染：结构视图关掉辉光、标出每一层的电子数，辉光视图按元素特征色发光；
- `←` `→` 逐个切换元素，`/` 搜索（`Fe`、`铁`、`iron`、`26` 都行）。

![铁的原子剖析](/element-atlas-118/atom.jpg)

整个项目没有一张外部图片、一个 3D 模型或一个字体文件。卡片是运行时用 Canvas 画出来的，构建后内联成一个 623 KB 的 HTML，断网双击也能打开。

## 怎么做出来的

代码全部由 AI 编程助手写，我只负责提需求和挑毛病。用的是 pi + DeepSeek V4.1 Flash，一个会话从下午五点跑到晚上十点。

最开始它根本不是周期表，而是一个「霓虹实验室」：实验台、四支放电管、高压旋钮、霓虹灯牌工坊，还带合成音效。做到一半我发现自己真正想反复点开看的只有元素周期表，于是把实验室整个砍掉，只留「周期表 + 元素剖析」。构建体积从 935 KB 掉到 606 KB，界面也清爽了。

之后的几轮基本都是同一类反馈：

1. **字太小**。我前后说了三遍「整站字体再加大」，最后一次复查时 CSS 里还剩一堆 6.5–9px 的字。AI 每次都只放大了它当轮注意到的那几处；
2. **看不懂中间那团球**。它一开始给核子数量设了上限，画出来的数量是错的。改成真实数量后，又补了一行说明：核子是密堆积示意，轨道是玻尔示意，不是真实的量子轨道；
3. **卡片上中英文贴在一起**。字号放大以后，元素符号和中文名几乎碰到一起，只能重新排卡片里的几行；
4. **剖析页要能左右切换**，不用每次都退回周期表。

几轮改完，它自己建了 GitHub 仓库，推上去开源。

## 第四个小时：「The. The. The.」

推送的时候我看了一眼它的思考过程，满屏都是 `The.`。

翻会话记录才看明白：这个会话的上下文涨到约 98.5 万 token，触发了一次自动压缩。压缩之后两分钟，思考里开始出现 `the caption; the pedestal; the label. The. The layout.` 这种越来越碎的句子，然后就只剩 `The.` 了。最后一个思考块有 22 万字符，里面是 31039 个 `The.`。

更麻烦的是它会自我强化：复读出来的思考被当成历史又喂回给模型，下一轮的上下文从 15.9 万 token 一下跳到 25.4 万，复读也跟着变得更严重。

奇怪的是工具调用一直正常。README 写得好好的，`git push` 也成功了，只是每一步之前都要先「The.」几万遍，白白烧 token 和时间。

处理很简单：停掉会话，把这个模型的思考档位从 `max` 降到 `medium`。同一个模型开 `medium` 的另一个会话，一直很正常。

> 教训：长会话 + 最高思考档位 + 自动压缩，是复读退化的高发组合。看到思考里出现大段重复，别等它自己恢复，直接停掉、换新会话交接。

## 上线后才发现的错误

当晚我让另一个 AI 把项目从头读了一遍再优化，它先发现了一个真正的错误：**电子排布是按构造原理（Aufbau）硬算的**。

构造原理对大多数元素成立，但有一批例外。铜（Cu）按规则算是 `3d⁹ 4s²`，实际基态是 `3d¹⁰ 4s¹`，因为 d 轨道全满更稳定。页面上原来显示铜的壳层是 M17 N2，正确的是 M18 N1。同类的例外一共 20 个：Cr、Cu、Nb、Mo、Ru、Rh、Pd、Ag、La、Ce、Gd、Pt、Au、Ac、Th、Pa、U、Np、Cm、Lr。

这种错误界面上看不出来，模型画得很漂亮，数字也像那么回事。现在按 NIST 基态数据逐个修正，档案里改成稀有气体简写（铜显示为 `[Ar] 3d¹⁰ 4s¹`），并校验了 118 个元素各层电子数之和都等于原子序数。

同一轮还做了：

- 全站字号统一放大，最小 10px；
- 元素搜索；
- 手机上可以从底部打开完整档案（原来窄屏直接把右侧档案隐藏了）；
- 修了一个内存泄漏：每切换一次元素，旧原子模型的材质和贴图都没释放。

## 几个技术点

- **118 张卡片只用 1 个 draw call**：所有卡片画在一张 2880×1800 的 Canvas 图集上，用一个 `InstancedMesh` 渲染，每张卡片的 UV、颜色、显隐和高亮都放在实例属性里；
- **光谱**：有可靠数据的元素用实测主谱线（比如氖的 585.3 / 640.2 / 650.6 nm），缺数据的用确定性近似，并在界面上标注「模拟谱线」；
- **单文件交付**：Vite 构建后，用一个 30 行的脚本把 JS 和 CSS 内联进 HTML。

## 做完的感受

AI 写 3D 场景、调光影、搭交互已经很顺了，真正要人盯的是两件事：

1. **事实对不对**。电子排布错了一整晚，没有任何报错，画面也很好看；
2. **AI 自己是不是还清醒**。思考在复读的时候，它的产出看起来照样正常。
