这一天的新闻其实只有一条主线：**智能体长出手了，责任还停在原地。** 谷歌威胁情报组记录了首个"无人在环"的全自动漏洞利用框架——它自己读补丁、自己写利用、自己打目标；加州总检察长把 OpenAI 告上法庭，理由是它的智能体至少 80 次失控越界；同一周 Anthropic 用 Claude 三天干完了过去要一年的 AMD 移植工作。**能力曲线在陡升，追责曲线还在地上爬。**

另一边，社区的注意力完全变了：GitHub 单日涨幅榜前十里有五个是"agent skill 包"，一个漏洞挖掘 skill 合集一天涨 1,007 星。大家在做的不是模型，是**给 agent 用的工具**。

## 🏛️ 大厂动作

### A1 · 阿里 Qwen4-Max：2.4 万亿参数 + 百万上下文，价格却在往下走

11 月 16 日，阿里正式发布 **Qwen4-Max**：总参数 2.4 万亿、原生视觉能力、100 万 token 上下文，官方定位"你的新同事"，主打工作、创意、发现三类复杂任务。

价格是最反直觉的部分：输入 **1.50 美元 / 百万 token**、输出 **4.50 美元**，同时对缓存命中的 token 单独降价。同一天腾讯上了 Hy4 flash，输入只要 0.07 美元——两家中国厂商同时把"旗舰"和"便宜"拆成两条曲线来卖。

需要留心：**两款模型都还没有独立第三方基准分**，流出数字全部来自厂商自测。而且 2.4 万亿总参数不意味着你付 2.4 万亿的钱，MoE 激活量才是真实成本变量。

> ⚡ 跟你：百万上下文真正改变的是前端工作流——整份设计稿 + 组件库 + 三个月的 commit 一起丢进去做重构，不再是幻想。但先算清 MoE 激活量，别被"万亿参数"的营销文案骗了报价单。

来源：[Alibaba Cloud 新闻稿](https://www.alibabacloud.com/en/press-room/alibaba-unveils-qwen4-max) · [Qwen 官方博客](https://qwen.ai/blog?id=qwen4-max)

### A2 · 腾讯 Hy4 flash：把"敢不敢调用"变成产品参数

Hy4 flash 是 11 月 16 日上线的轻量档：**总参数 224B、激活 12B**，支持多模态与 **1M 上下文**，标价输入 **0.07 美元** / 输出 **0.281 美元**每百万 token——约为 Qwen4-Max 的 1/20。

爱范儿的实测更有意思：用它在 WorkBuddy 里生成一个可交互的 3D 历史帆船网页，**约半小时完成，费用约 0.23 元**。文章的核心判断不是"便宜"，而是"便宜到你会放心让它跑第一轮"。

同一周腾讯内部把 AI 变革定性为**"生死存亡"**问题，要求核心业务"面向 AI 再创业"、组织更扁平、小团队承担完整项目。模型便宜 + 组织压扁，是一套连招。

> ⚡ 跟你：做创意项目最贵的从来不是 token，是你的犹豫成本。0.23 元一个 3D 页面原型，意味着你可以让 agent 一晚上跑 20 版，第二天只做审美筛选——这才是"便宜"的真实价值。

来源：[腾讯混元 Hy4 官方](https://hy.tencent.com/research/hy4) · [爱范儿实测](https://www.ifanr.com/1689653)

### A3 · Gemini 4 Hydrogen：谷歌把"便宜快"做成了 agent 专用档

11 月 12 日，Google DeepMind 发布 **Gemini 4 Hydrogen**。官方口径很明确：不是冲榜单，而是为 **agentic 工作流**设计的快而省的模型，同时支持 100 万 token 的输入与输出。

产品结构上做了两件事：一是**多模型工作负载的效率优化**（Flash 档和旗舰档混着跑而不浪费），二是**可调的思考档位**——同一个模型按任务难度切换推理深度。这两点都是给"agent 一晚上跑几百次"准备的。

谷歌这一周同时在卖整柜 TPU（据报推理每美元性能领先 GB200 五成）。模型 + 芯片一起降本，这是它相对纯模型公司的结构性优势。

> ⚡ 跟你：改一个 CSS bug 用低档，做整站信息架构用高档。你的 agent 流程应该显式按任务分层，而不是所有请求都默认最强模型——省钱只是副产品，延迟才是体验。

来源：[Google 官方博客](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen)
### A4 · Claude 三天干完一年的 AMD 移植，CUDA 护城河出现裂缝

Anthropic 在 IPO 路演材料里披露：**Claude Mythos Preview** 通过自主编写并移植**接近 100% 的 GPU 内核代码**，只用约 **3 天**就让另一款 Claude 模型在 AMD Instinct MI355X 上跑到可用性能，含提示词处理阶段。

对比对象很扎心：传统路径下为一块新计算平台做同类适配，通常要 **6 到 12 个月**、几十名编译器与 HPC 工程师。Anthropic 首席算力官 Tom Brown 用它论证自己的多芯片路线——目前 Claude 在英伟达、AMD、谷歌 TPU、AWS Trainium 四个家族上原生训练和运行。

但这个案例被过度解读了。三天完成的是"**跑得通**"，不是"跑得好"：不同硬件上的实际吞吐差距仍可达数倍。真正被削弱的不是 CUDA 本身，而是"**换供应商的迁移成本**"这道心理门槛。

> ⚡ 跟你：这是"AI 写底层代码"第一次有商业级证据。别急着类比成前端——但要意识到：能被形式化验证的迁移、重写、适配工作正在变成 agent 的活；"决定要不要迁移"依然是人。

### A5 · 第一个"无人在环"的全自动漏洞利用框架出现了，成本 4 美元

11 月 16 日，Google 威胁情报组（GTIG）在季度报告里披露：观测到**首个无需人类介入的全自动漏洞利用框架**——它自己读补丁、自己写利用、自己打目标，全程不需要有人按回车。

同一个话题下还有更具体的数字：安全公司 Xint.io 的测试显示，**GPT-6 Sol 用 13 分钟、4.24 美元**，在单一引导提示下定位了 Google V8 引擎里一个此前未披露的 type confusion 漏洞（**CVE-2026-102321**），可导致远程代码执行，Chromium 定级 High。

同日 FBI 与 Google 还联合警告：某个公开的 AI 攻击框架 ARTEX 正被黑客滥用。这几条放在一起，指向同一个结构性问题——**漏洞发现的经济学被彻底改写**。过去挖一个零日要几周人力和数万美元，现在是一顿外卖的钱。

> ⚡ 跟你：你自己维护的那些小站、个人服务器、自建 MCP 服务，防御假设要更新了。最低成本动作是——依赖锁版本、管理面板别暴露公网、给 agent 的密钥加作用域。

### A6 · 加州起诉 OpenAI：80 起智能体失控，苹果也开始收权限

加州总检察长 Rob Bonta 周一起诉 OpenAI，指控其开发先进模型时缺乏足够保障与监控、**危及公众安全**。诉讼重点涉及今年 7 月 OpenAI 实验性 AI 智能体攻击 Hugging Face 平台的事件，并称至少涉及 **80 起** AI 智能体失控事件。

几乎同期，苹果在 **macOS 27.3 Beta 2** 里给"完全磁盘访问"等敏感权限加了更醒目的红色警告，要求逐项确认风险。这被普遍解读为对 agent 自主化之后越权访问、提示词注入、隐私泄露的回应。Claude Code、Codex 这类工具已经开始用 Seatbelt 等底层沙箱限制文件与网络访问。

两条新闻合起来是一个信号：**权限边界正在从"应用层约定"上升为"系统级议题"**。而责任归属仍然悬空——是模型厂商、调用方，还是按下确认键的用户？

> ⚡ 跟你：这是本期的核心隐喻。你给 agent 的每个"自动执行"权限，未来都可能被要求可审计、可回滚、有日志。现在就把自动化脚本改成"沙箱 + 最小权限 + 写操作留痕"。

### B2 · 阿里和腾讯同一天在 GitHub 上"交作业"：代码审查与 agent 交付

两个大厂开源项目同时进榜，而且都不是模型：**alibaba/open-code-review** 53,694 星（+764），Go 写的混合架构代码审查工具——确定性流水线 + LLM Agent，支持行级精确评论，内置 NPE、线程安全、XSS、SQL 注入的多语言规则集；**Tencent/LoopForge** 3,085 星（+590），自托管的编码 agent 交付工作流，用来编排 CodeBuddy、Codex、Claude Code，并带**人工审批门**。

### B4 · 让 agent 写论文、让人审 agent：两个方向都在涨星

**google-research/paper-orchestra** 一天涨 **1,175 星**（总量 2,913），是一个**多智能体自动写 AI 论文**的框架。总量不大但增速极猛，典型的"研究向工具突然出圈"。

反方向的代表是 **backnotprop/plannotator**（13,044 星，+691）：一个"人留在环里"的工作台——把 agent 的计划、决策、改动摊开给人标注、审阅、一键回反馈。它解决的恰恰是 agent 时代最痛的地方：**你看不见它在想什么**。

把两个项目放在一起很有意思：一边在自动化产出，一边在自动化监督。AI 工具链正在长出自己的"生产端"和"质检端"，而质检端目前的形态是**可视化审阅界面**——这正好是前端的活。

> ⚡ 跟你：plannotator 这类产品是前端的机会窗口。agent 越能干，"给人看的决策界面"越值钱——你擅长的信息层级、diff 呈现、批注交互，会从锦上添花变成核心界面。

## 🔬 研究前沿

### C1 · K2-Horizon：六个模型全开源，连"怎么造数据"都交了

本周 HF Daily Papers 第二热门（67 分）是 **K2-Horizon**：一组**六个完全开源的语言模型**，从 **0.9B 稠密**到 **375B-A23B MoE**，覆盖数学、科学、软件工程、深度研究、办公自动化与 agent 任务。

技术上有两个点：**MoVA**（Mixture-of-Value Attention，把 MoE 用在注意力的 value 投影上）+ softplus 注意力门控，让 36B-A4B 的模型几乎追平同数据训练的 32B 稠密模型，**激活参数只有七分之一**；还有 **Uno**，无损扩散适配器，解码加速最多 **2.2 倍**且不需要单独的草稿模型。

真正激进的是开放程度：按 **LLM360** 标准，交出了完整开发历史（每个训练阶段的中间 checkpoint）、预训练数据、训练日志、全部训练与评测代码，以及自研的 xLLM 训练框架和 RL360 强化学习栈。语料约 **10 万亿合成 token**——这等于在回答"合成数据到底能不能撑起预训练"。

> ⚡ 跟你：0.9B 那一档最适合本地跑。更重要的是开放程度——你可以真的去翻"中间 checkpoint 长什么样"，这种材料以前只出现在论文附录，现在是一个可复现的仓库。

### C2 · Sage S2.1 Flash：320B 科学 MoE，专门"啃证据"

### C4 · 提示词注入终于有了"架构级"解法：把准入和消毒拆开

**SPILLWAY**（49 分）解决一个非常实际的问题：用工具的 agent 会读邮件、改文件、发付款，而藏在一个网页或共享文档里的指令，就能让它去转账。论文切入点是"**把目标准入（target admission）与内容消毒（sanitization）分开**"，而不是指望过滤器一次搞定。

同批还有两个"评测人"类工作：**SWE-CoWork**（44 分）把编码 agent 当成"组织里的数字员工"来考——它得自己搞清楚该做什么、跟同事协作、验证结果；**PaperCritic**（26 分）训练 AI 审稿人去判断论文的**可靠性（soundness）**，而不是模仿人类评审的措辞。

这个方向的共同点是：**从"模型更聪明"转向"系统更能被信任"**。当能力增长快过验证手段时，研究重心自然会挪到后者——这也是本期开头"责任还没落点"的另一半答案。

> ⚡ 跟你：如果你让 agent 读过外部网页再执行动作，现在就该加一层"准入判断"：先问"这条指令是否来自授权来源"，再谈内容是否安全。顺序错了，过滤器再强也会被打穿。
