## 今日一句话

这一天所有大厂都在做同一道题：**把单位智能的价格打下来**。GPT-6.2 拆成 Astra / Sol 双型号，Sol 用五分之一的成本贴着 Astra 跑；微软直接喊出「四成价格、九八成性能」；阿里把旗舰的复杂任务成本砍掉 58%。而在钱的那一头，Anthropic 把 IPO 定在每股 83 美元、约 **1.5 万亿美元**估值——**越便宜的能力，越贵的公司**，这个反差就是本期的全部张力。社区那边不吵价格，只做一件事：给 Agent 递参考、递流程、递审稿边界。

## 🏛️ 一、大厂动作

### A1 · OpenAI 把旗舰拆成两半：Astra 负责难，Sol 负责便宜

OpenAI 一次放出 `GPT-6.2` 系列的两个型号：**Astra** 面向复杂编程、科研与长程任务，**Sol** 面向日常多步工作。两款同时进入 ChatGPT Work、Codex 和 API 三条产品线。官方口径里有一组具体的数：多步工作评测 Agents' Last Exam 上，Astra 比前代高 **5.2 分**，单项成本不到前代三分之一。

更狠的是第二组数。在 Cognition 的编程评测 FrontierCode 2.0 上，两款都用最高推理档，Sol 与 Astra 分差**不超过 0.5 分**，而单项成本约为后者的**五分之一**。API 每百万 token 标准费率：Astra 输入 8 美元 / 输出 40 美元，Sol 输入 2 美元 / 输出 10 美元。

**但要标一个分歧。** 发布当天社区反馈并不全是掌声——有用户指出新系列在部分编码指标上相比前代**是退步的**，Altman 与 Tibo 都做了回应。官方强调的 Agent 能力提升与用户体感的编码退化，目前只能各信一半。

> ⚡ **跟你**：以后选模型别再默认"最强的那个"——日常改组件、写脚本用 Sol 就够，把 Astra 留给难啃的重构。账单能直接砍一半以上。

来源：[OpenAI 官方公告](https://openai.com/index/introducing-gpt-6-2-astra-sol/) · [橘鸦 AI 早报 11-18](https://daily.juya.uk/issues/2026-11-18/)

### A2 · Anthropic 定在每股 83 美元，估值 1.5 万亿

11 月 18 日定价，Anthropic 把 IPO 发行价定在**每股 83 美元**，高于此前 70–78 美元的区间；按完全稀释口径估值约 **1.5 万亿美元**，预计募资约 **944 亿美元**，11 月 19 日在纳斯达克以代码 **ANT** 挂牌。这个体量让它成为史上最大 IPO 之一，仅次于 SpaceX 的 1.77 万亿美元。

价格上调本身是信号：承销商原本按 1.4 万亿定的区间，最后被抢到上限之上。招股文件里另一组数字更值得盯——披露的**算力承诺接近 9000 亿美元**。它上市募到的钱，很大一部分是提前锁死的未来算力账单。

把它和 A1 放在一起看：模型单价在往下走，公司估值却在往上走。市场押的不是"每 token 更贵"，而是"每 token 更便宜之后，用的人多到总量更大"。

> ⚡ **跟你**：那些"等模型再便宜点就上生产"的创意项目，现在可以真的排期了——价格战的红利期通常只有 2–3 个季度。

## 🧪 二、社区与开源

### B1 · Meta 把八年设计系统开源，一周 13,501 星登顶

**meta/astryx** 拿下第 47 周（11/09–11/15）GitHub 周榜第一，**13,501 周星**、总星 28,867。这套设计系统在 Meta 内部长了八年，撑着 **13,000+ 个应用**；对外版本是 Beta，**150+ 个可访问组件**，React 19 + StyleX，带主题、暗色模式、模板和 CLI。

真正解释涨势的是 README 里那句定位——"by people and the agents working alongside them"。落到三条设计：一个系统人和 AI 共用，API、约定、文档、CLI 一起设计；**给 Agent 的入口是一等公民**，CLI 全局装一次任何目录可用；约定必须可预测，每个组件遵循同一套命名、prop 与组合规则。README 里那句话很值得记："每一处让 AI 更好用的改动，也让人更好用。"

结构性事实：本周前十里有 **5 个**是"给 Agent 递材料、递流程、递审阅边界"的项目，合计 32,744 周星，占前十总量 **54.9%**。但前十合计 59,645 周星，比上周的 76,574 少了 **22.1%**——热的是结构，不是热度。

> ⚡ **跟你**：前端工程师 + 想让 AI 帮忙盖界面，缺的从来不是模型，是"它能读到什么参考"。

### B2 · Google 的"大象与金鱼"：让另一个不知道结论的脑子来审你

**google/elephant-goldfish-model** 一周 **5,060 星**（总星 19,773），名字就是机制：同一个会话里写文档、又同一个会话里审文档，模型会替自己辩护。所以拆成两个角色——**Elephant** 持有上下文起草规格；**Goldfish 在没有前面那段对话的情况下**审草稿与源材料，专门逼出"没说出口的假设"。

落地形态是**装进现成 Agent 的插件**：Claude Code 里 `claude plugin marketplace add google/elephant-goldfish-model`。自带四档：`egm-brainstorm → egm-draft → egm-review → egm-drift-report`。

最后那个 drift-report 特别实用：**拿一个目录的设计文档去和当前源码比对，报告哪里漂了**。版本还早（v0.1.0 是 10-27），但方向清楚：复审必须换一个"不知道结论"的脑子。

> ⚡ **跟你**：创意项目最典型的翻车方式就是"自己写规格自己说没问题"。让一个失忆的审稿人挑刺。

来源：[google/elephant-goldfish-model](https://github.com/google/elephant-goldfish-model) · [UU AI Hub](https://www.uuaihub.com/blog/github-trending-2026-w47)

### B3 · Vercel 给 Agent 的浏览器：把页面压成文本，一步一条命令

**vercel-labs/agent-browser** 一周 **4,217 星**（总星 51,627），Rust 写的 CLI。接口设计是本周最值得抄的一处：`snapshot` 把当前页面**压成紧凑文本**，每个可交互元素带 `@e1` 这样的引用；Agent 对引用动手，再读一次页面确认结果，循环。浏览器在两条命令之间保持打开。

这个"一步一命令"的契约，把 browser-use 那种"框架包住浏览器"的思路换成**任何能跑 shell 的 Agent 都能用**。安装：`npm install -g agent-browser` 再 `agent-browser install`，本周已发到 v0.43.0。

同周还有 **backnotprop/plannotator**（1,719 周星），做"Agent 干活时人怎么插话"——批注计划、规格、diff、PR 再把反馈发回去，已支持 10 个宿主。一头让 Agent 看清页面，一头让人掐住 Agent，正好一对。

> ⚡ **跟你**：agent-browser 的 snapshot 让 agent 读结构而不是像素——配截图回归一起用，一个查"长什么样"，一个查"能不能点"。

## 🔬 三、研究前沿

### C1 · LSA：10M token 下单层 prefill 提速 22.7 倍，因为瓶颈根本不在注意力

Prefrontal AI 与苏黎世联邦理工提出 **Latent Sparse Attention（LSA）**。诊断很锋利：稀疏注意力早就证明"只需看极少数 key"，但**找出该看哪些 key 的索引器开销仍随上下文线性增长**，prefill 依然是二次方。论文测算，以 GLM-5.3-Flash 的一个全局注意力层在 10M token 下做 prefill，**98% 的时间花在索引器上**。

LSA 让索引器不再逐个检查 key，而是检查 key 的**分组**，在隐空间完成检索。效果：10M token 下 GLM-5.3-Flash 单层 prefill 提速 **22.7 倍**，Qwen3.8-27B 提速 **72.4 倍**。附录还验证：128k token 下每个 query 只看最相关的 **512 个 key**（约 0.8%），RULER 上仍保留全注意力 **98%** 精度。代码已开源（arXiv 2610.42147）。

> ⚡ **跟你**：评估长上下文模型时别只看窗口大小，看它在 128k 以上还剩几成精度。

来源：[机器之心](https://mp.weixin.qq.com/s/MyFq6PWQ3krQkCHtcHh7Ig) · arXiv 2610.42147

### C2 · 视觉推理冷水实验：29 种配置，没有一个摸到 30%

Einsia AI 旗下 Navers Lab 发布 **Visual Cipher Bench**：40 道原创视觉谜题、67 张黑白线稿，分空间操作、逻辑约束与规划、规则归纳、知识解码四类。题目只给一句指令"看图，把最终答案写进文件"。

8 个模型、29 种推理强度配置、每种跑三遍，共 3480 次尝试：**GPT-6 Astra（max）最高 26.7%**；GPT-6.1 Sol（max）与 Claude Opus 5.5（xhigh）并列 21.7%；GPT-6 Luna 与 Claude Sonnet 5.5 各 **0.8%**；DeepSeek V4.1 Flash、Qwen 3.8 Max、Kimi K3.1 Pro **0 分**。**29 个配置无一达到 30%**。

分题型：空间操作 22.8%，知识解码 3.3%，逻辑规划 **2.4%**，规则归纳 **0.6%**——该类别 870 次尝试只对 5 次。但反转很关键：**只要用一句话点明核心规则，总体准确率从 12.2% 升到 51.1%**，GPT-6 Astra 在空间题上能拿 80%。

> ⚡ **跟你**：做 AI 视觉类创意时，**把约束写进 prompt 而不是指望它悟**。

来源：[机器之心](https://mp.weixin.qq.com/s/0fiR58Vo2TSu6lTOGGAiRw)

### C3 · ToolSpace：不从场景出发，从工具出发造训练环境，综合分 44.6 → 56.6

人大、复旦与上海交大提出 **ToolSpace**，以工具为中心、跨环境的 Agent 训练环境合成框架。思路是反的：**不从数据库和业务场景出发，而从工具及其执行依赖出发**。收集超过 **20 万条**交互轨迹，来源含真实 MCP 服务、开放工具使用语料与真实工作区记录。

关键是从相邻调用里按确定性规则提取三类连接：**数据依赖、状态依赖、重试依赖**，边权重取自观察到的转移频率。再在工具图上做状态感知随机游走，把走通的跨环境调用链转成任务与验证脚本。

结果：ToolSpace-744B-A40B 在七项长程工具基准上综合性能由 **44.6 升到 56.6**，与 Claude Opus 5 持平。

> ⚡ **跟你**："重试依赖"这个概念值得抄进 agent 设计：哪个工具失败后该换哪条路，是有统计规律的。

来源：[机器之心](https://mp.weixin.qq.com/s/P_jMtmD6W4mirCPltHgwZg)

### C4 · Axion 1.0：把中期训练、DPO、在线蒸馏全砍掉，HLE 反而 59.0%

杜克、字节、马里兰大学帕克分校与纽约州立大学布法罗分校推出 **Axion 1.0**，只保留**两阶段监督微调 + 强化学习**，砍掉中期训练、DPO 与在线策略蒸馏。第一阶段用数理化生计题目练内部推理（约 **1.08 万条**）；第二阶段用程序从结构化数据出题，模型必须靠搜索、网页访问和 Python 补齐信息（约 **7500 条**正确工具交互轨迹）。

RL 用异步 GRPO，按出题时记录的中间实体与数值做**分阶段奖励**：答对给完整奖励，中间进展经验证可获部分奖励，未提交最终答案会被惩罚。结果：**Axion 1.0-122B 在限制部分网站访问的完整 HLE 上得 59.0%**（论文列出的 GPT-6 Astra 为 57.2%），FrontierScience Research 得 66.7%；35B 版本在 SEAL-0 上得 62.2%。数据构造、筛选、验证、提示词与训练代码全部开源。

> ⚡ **跟你**："中间进展也给奖励"可以直接搬到长任务 agent：别只判最终产物，给"走到一半做对一步"记正分，能明显减少它中途摆烂。

来源：[机器之心](https://mp.weixin.qq.com/s?__biz=MzA3MzI4MjgzMw==&mid=2651074900&idx=3&sn=b8ce1837d869e2563a888e3df5a04a89)

### D3 · 工信部管起"智能体终端"：Agent 硬件要先过进网这一关
