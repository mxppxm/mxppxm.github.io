## 🏛️ 大厂动作

### A1 · Anthropic 双发 Fable 5.2 与 Mythos 5.2，定价直接把"长程活"标了价

11 月 9 日，Anthropic 发布 **Claude Fable 5.2** 与 **Claude Mythos 5.2**，官方定位是"最擅长啃硬技术活的模型"——长时间自主软件工程、复杂推理、1M token 上下文。两个模型均为闭源，走 API 分发。

价格是本期最值得记的数字：**输入 $8 / 百万 token，输出 $40 / 百万**；"快速模式"翻倍到 $16 / $80。这个价位已明显高于主流档，说明 Anthropic 不打算在价格战里跟，而是把"能跑很久的 agent 任务"单独切成一个高价位商品。

官方跑分是 **FrontierCode 2.0 的 49.1%**（Xhigh 预算档）与 **FrontierSWE v2 的 69.9%**。需要标注：两项都是 Anthropic 自家口径，第三方独立复现尚未公布；而同期 METR 的评估反而指出了算法进展速度、未发布模型囤积等问题（见 C1）。

**⚡ 跟你**：它贵得很有针对性——按 token 计价意味着"跑二十轮才出一个 PR"的 agent 流程成本会很难看。真正该用的是混合策略：探索阶段用便宜模型，最后收敛阶段才切 Fable。

### A2 · Gemini 4 Carbon 开放，谷歌用"半价三十天"换长程能力的心智

11 月 10–11 日，Google 把 **Gemini 4 Carbon** 从预览推到一般可用：Gemini API 付费档（模型 ID `gemini-4-carbon`）、Google AI Studio，以及 Google AI Ultra 订阅（日本区 14,500 日元/月）在 Gemini App、搜索 AI Mode、Antigravity 里逐步放量。

官方给的能力重心是两个很少被放在一起说的词：**前沿网络安全**与**长程规划执行**（Long Horizon）。评估覆盖 agentic coding、computer use、知识工作、科学数学、多模态、长上下文与网络安全，评估文档谷歌自己公开了 PDF。

定价很有攻击性：**引入期 $2 / 百万输入、$10 / 百万输出，11 月 30 日后回到 $4 / $20**。比 Fable 5.2 便宜一档还多，但在"长程"这个卖点上正面撞车。

**⚡ 跟你**：11 月 30 日是硬截止——需要跑批的脚本（批量生成插图、批量改页面），这个月之内跑完比下个月省一半。这种"限时价格窗口"值得写进任务排期。

### A3 · 混元 Hy4 正式版：第一次有了眼睛和手，价格没动

11 月 4 日腾讯发布混元 **Hy4** 正式版。前身 8 月的 Hy4 preview 总参数 **770B**、激活 **49B**、上下文突破 **1M**，是当时国产开源里体量最大的 MoE 之一。

正式版改动集中在三处：显著扩大预训练与后训练规模；**首次引入视觉能力**，可解读图表与文档；加上**电脑操作能力**（图形界面与命令行）。场景上押注办公协同与游戏开发——与腾讯 IEG 合作，重点提升 UE / Unity 下的功能实现、玩法逻辑与状态理解。

最关键的商业细节是**价格没变**：能力加了视觉和 GUI 操作，单价没跟着涨。这在 11 月这轮涨价/分层定价的潮流里是反向操作。

**⚡ 跟你**："看图改界面"终于有国产便宜选项——把设计稿截图丢进去让它直接改 CSS，或者让它读构建报错截图，比纯文本描述省一大段来回。

### A5 · OpenAI 造了一把专用锤子：GPT-6 Cyber 在 Firefox 里挖出 81 个严重漏洞

11 月 5 日，OpenAI 发布 **GPT-6 Cyber**——不通用，专门用来找并利用软件缺陷。官方称它在多数网络攻防任务上超过主力模型 **GPT-6 Astra**，测试期间仅在 Firefox 浏览器就发现了 **81 个新的严重漏洞**。

和以往"给你一个可疑位置"的模型不同，它能在真实代码库中**复现并验证**缺陷——输出从"线索"变成了"证据"。分发上只面向防御方与通过审核的安全团队。

同期 Anthropic 的 Glasswing、Google 的 Fairwind 也向审核者开放了"公开模型会拦截的攻击能力"。安全模型的军备竞赛已经独立成一条产品线。

**⚡ 跟你**：注意这个产品形态——能力太强就"只卖给防御方"。你自己做的东西如果碰到安全敏感能力，迟早也要面对准入设计问题。

### A6 · 一周三起：推理服务成了新的漏水点（风险类）

11 月 8 日，**NEAR AI** 的云端推理服务被攻破。攻击者利用 **SGLang 的远程代码执行漏洞**，导致约 **100 名用户**的数据与 18 个旧版 AI Agent 的信息泄露——含邮箱、姓名、订阅详情、聊天记录，以及两名云客户的 API 密钥（均已撤销）。

几乎同时，**Fireworks AI** 披露另一起因第三方云被入侵导致的二次泄露，牵连 **Notion**：不到 1% 的工作区受影响的、无法归属到具体用户的 AI 聊天记录被暴露，Notion 已停用 Insights 功能并停止用 Fireworks 提供开放权重模型服务。

第三起是监管口径：**韩国个人信息保护委员会（PIPC）11 月 10 日对 Anthropic 启动正式调查**，涉及约 100 个韩国企业账户的数据泄露，Anthropic 于 10 月 31 日主动披露。三件事合起来说明：**推理层（SGLang / vLLM 这类服务框架）是当前最脆的一环**，不是模型本身。

**⚡ 跟你**：真在自己机器上自建推理服务，别只改端口——这些框架的 RCE 是"拿到就全拿走"。最少做到：只监听 127.0.0.1、前面套一层带鉴权的反代、key 别写进前端。

来源：[Gate News 11/10](https://www.gate.com/zh/news/detail/near-ai-restores-cloud-after-sglang-breach-exposed-100-users-25527781) · [LavX News 11/10](https://news.lavx.hu/zh-Hans/article/notion-cheng-fireworks-ai-shu-ju-xie-lou-shi-jian-bao-lu-le-bu-fen-wu-fa-gui-shu-de-ai-liao-tian-ji-lu)

## 🧪 社区与开源

### B1 · 8 天 16.4k 星：一个"少占用你注意力"的常驻 agent 换了榜首

据 GitHub 周榜（11.03–11.08）统计，`deepseek-ai/dsh-superagent-prototype` 建仓仅 8 天，**总星 16.4k、单周涨 14,286 星**，直接顶掉上期榜首。

机制值得细看：它是给**单个仓库**配的常驻 agent，打包成 DeepSeek Harness 的一个 bundle。监听 GitHub（可选加飞书），被允许的人在里面派活时，它开一个 work item，在自己的会话和目录里干完，再回到原对话里回复——通常是一个 pull request。配套 Web 面板只列出**需要人拍板的事**。

README 写得很诚实：这是**研究原型，不是官方产品**，大量工程由 coding agent 完成，可能带 bug、风格不统一，用之前要先 review。"能替整个团队动手的 agent，同样能浪费整个团队的注意力，所以它只在被请求、或团队写下的规则允许时才动"。

**⚡ 跟你**："只在被请求时才动"这条约束，比任何架构图都值得抄进你自己的 skill 设计里。自动化脚本最大的风险从来不是能力不够，而是自说自话地干了一堆没人要的事。

### B2 · unslop：一个专门治"AI 味"界面的 skill，单周涨 3,945 星

`heydamir/unslop` 建仓于 11 月，**总星 7.3k、周增 3,945**，定位是"专治 AI 生成感界面的 Agent Skill"，装进 Claude Code、Codex 或 Google Antigravity 就能用。

它的聪明之处在于**把"AI 味"拆成了可检查的具体项**：紫渐变、发光边框、emoji 标签、喊话式文案、不均匀的间距。找到之后不直接动手，而是先从产品里定一个方向——性格、世界观、一两个承载颜色的时刻、一个签名细节——把方案摆出来让你纠偏。

修改顺序是固定的：间距 → 颜色 → 图标 → 文案 → 字体 → 布局 → 细节 → 视觉 → 动效。技术栈不限（Next.js / React / Vue / Svelte / Tailwind / 纯 HTML+CSS），只给一个线上链接也能对着改。最讨喜的一点：**如果界面本来就不错，它会直接说"别改了"**。

**⚡ 跟你**：这就是"审美判断的可执行版"——把主观偏好写成一套带顺序的检查清单。完全可以照它的结构，把自己的审美偏好蒸馏成一个 `design-review` skill，它做的正是你想让 AI 学会的那部分。

### B3 · dsh-Go：把 agent 塞进安卓手机，不用 Root

`ccch1mneyyy/dsh-Go`（周增 **4,915 星**，总 7.3k，AGPL-3.0）是 Flutter + Kotlin 写的 Android 客户端，思路是"给 agent 配了台手机"。

技术上有两个真东西：内置一套 Linux 运行环境，**不用 Root、不用另装 Termux** 就能在手机里装好 Ubuntu、Node.js 和 DSH 引擎；不想占空间也可以用 SSH 或 DSHarness Remote 直接连电脑/服务器上的 DSH。本机跑引擎建议预留约 **1GB** 空间，要求 Android 8 以上。

交互细节很到位：回复中途能插话、排队消息可立即发送、过程自动折叠成一行、对话可生成端到端加密的回放链接。还有两个桌宠会在你确认、跑完、睡觉时换动作。

**⚡ 跟你**："手机当瘦客户端、电脑当推理机"这个组合，比在手机上硬跑模型现实得多。你想在通勤路上用自己那套 skill，照这个思路做远程连接层就行。

### B4 · craft-anything：用"只看截图"的干净房间，复刻任何一个网站

`storytold/craft-anything` 周增 **3,836 星**、总 7.7k，引擎是纯 Rust，四步走：研究原目标 → 让编码 agent 用指定语言和框架新建项目 → 把成品和原版逐项对比 → 按差异继续打磨。第一步和第三步都留证据，不是"看起来差不多"就收工。

最有意思的是默认的 **clean room 模式**：不读原目标的代码和文件，只使用访客能看到的东西——截图、可见文字、量出来的布局、颜色、字体、间距。要读代码得手动切 Deep 模式。**320 个工具**每一个同时是 CLI 子命令和 MCP 工具，agent 不打开图形界面也能驱动整套流程。

限制也说清：early alpha，构建阶段依赖本机 Claude Code；clean room 只是"它自己不看"，**不是操作系统级沙箱**。

**⚡ 跟你**："先量出来再写代码"对前端是降维打击：它把"还原度"从主观变成可 diff 的数字。下次改版可以拿它当基线对比工具，比肉眼找茬靠谱。

### B5 · Mika：一块"隐藏的后台屏幕"，让 AI 替你点手机

`wangzan101/Mika` 周增 **3,339 星**、总 6k，是安卓上的本机 AI 助手。最舒服的设计是那块**隐藏的后台屏幕**——开 App、点按、输入、滚动都在另一块屏幕上进行，你照常用自己的手机，想看时点一下小窗。

因为不依赖任何 App 的 API，它像真人一样看屏幕找按钮，微信、小红书、招聘软件、购物网站一视同仁。演示很具体：让它读微信群今天聊了什么、找 30 美元以内 4.5 星以上的充电器加进购物车、总结某个博主的近期笔记。它会记住偏好，也会把做完的任务沉淀成**技能**。

隐私是加分项：**没有 Mika 服务器**，用自己的 key 或登录 ChatGPT / xAI / OpenRouter，记录都留在手机上。默认 Ask 模式只在花钱（下单、支付）前才问你。

**⚡ 跟你**："把一次成功的操作沉淀成技能"——这是 agent 真正该有的记忆形态：不是记住聊天，是记住流程。重复的部署/发布动作完全可以照这个模型做成可复用 skill。

### B6 · OpenBot：给"AI 同事"配一台电脑，还能自己托管

`CopilotKit/OpenBot` 周增 **2,813 星**、总 10k。定位是"给 AI 同事用的可自托管工作台，带企业级治理"：每个 bot 有自己的一台电脑——浏览器、文件、工具，**每个动作先决策、后记录**，可以随时接管。

模型自己挑（OpenAI / Claude / Gemini 或任何 OpenAI 兼容端点），云上或自己机房都行；已有 agent 通过 **AG-UI** 接进来，工具走 **MCP**。模板是 MIT 的，想白标、想深改都不拦。部署分两档：笔记本上装个自带 Docker 后端的桌面应用就能试；团队用提供 Helm chart。企业版加公司登录、角色、工具权限、审批与审计。

### C1 · METR：Anthropic 的算法进展速度约为原先两倍，而且在囤未发布的模型

METR 对 Anthropic 的第三方评估给出了一个让人不太舒服的结论：其**算法进展速度约为原先的两倍**，公司正在用现有模型训练未来的模型，并**囤积多个未发布模型**。

更值得注意的是信息完整性问题：Anthropic 以"避免加速其他开发者"为由，**删节了 METR 认为最有信息量的证据**（含算法进展估计与未来模型预测），并在过程中途取消了"算力在能力与安全之间如何分配"的审查。

把这条和 A1 并排读：同一天发布的两个旗舰，一个在宣传长程自主能力，一个在披露自主迭代的速度翻倍。递归自我改进（RSI）从"理论担忧"变成了"审计报告里的一行数字"——而这份审计还被删过。

**⚡ 跟你**：当供应商的能力曲线被"删节"过，唯一能信的就是自己的实测。给关键流程留一套固定 eval 集，比看任何跑分都稳。

### C2 · 可验证推理：用密码学证明"这条回答确实来自你授权的那个模型"

Anthropic 在 11 月 2 日公开的研究方向叫**可验证推理**（verifiable inference）。要解决的问题很具体：推理服务器一旦被攻陷，攻击者或失控 Agent 可以窃取权重、向用户投放恶意响应并混在真实响应里难以察觉；更高级的模型甚至能**顶替被授权的模型**对外服务。

思路是用密码学手段证明每次输出确实来自指定的那个模型——把"模型身份"从一句合同条款，变成一条可验证的运维事实。

这跟 A6 那三起泄露是同一个问题的两面：推理层是信任链上最薄的一环，而目前几乎没有产品级的验证手段。
